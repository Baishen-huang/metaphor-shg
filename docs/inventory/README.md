### 1.2 准则（139 项）

**硬门槛只有 4 个**（P1 <15% Go/No-Go、P0 ≥300 框架、P2 >85%、P3 >70%），

内联数值比较（~20）、文档 prose gates（~10）。

**三个最值得关注的无依据取值**：

1. `extractor.py:46` 的 `llm_conf_threshold = 0.5` —— 唯一「默认值即撞穿硬门槛」
   的参数（实测 P1 = 32.9%）；全部 12 个生产模块都显式覆盖为 0.85。
2. `context_budget.py` 自适应阈值整组 —— 不是"未验证"，而是**已验证为恒等函数**：
   `tau0 − decay·max_decays = 0.0`，衰减空间恰好用尽；实测 n=5/17/49/50/51/200
   全部返回 100% 候选，high 档从未触发。A8 的"中性结论"是**结构必然**。
3. `training.py` 人工权重 0.35/0.25/0.20/0.20 —— 纯手拍，struct 过权 37 倍。
   后果已量化：仅校正权重（不训练模型）MRR 0.4809 → 0.5496，**反超**训练后 0.5447。

## 2. 跨清单的共性发现

### 2.1 「软通道无法影响布尔指标」——四代负面结果的统一机制

每一个软信号通道（溯源可靠性、Ω、HGNN 校验）都**结构性无法影响 P1**，
因为 P1 是存在性布尔量（`pred = bool(edges)`）而软通道作用于排序。
唯一例外是 `struct` 特征里的 `cascade_id` 非空布尔位——它本身是布尔量。

### 2.2 「比较公平性」是系统性盲区

三处同类缺陷（已修）：§6.1 池饱和 ｜ §6.2 权重错配 ｜ §6.4 A6 两臂预算不对等。
已固化为论文 §4.1「比较公平性声明」+ `audit_fairness.py` 自动检查。

### 2.3 「渐近命题不能解释有限步行为」

最容易犯的推理错误。实例：无源项算子在 500 步收敛到分量共识（余弦 1.000），
但 H4 工作在 `layers=2`（余弦仅 0.383）——「0.950 是退化造成的」被证伪
（完美同分量指示器上限仅 0.800 < 0.950）。

### 2.4 编排者的 5 处自身错误，共同模式是「外推前未确认适用条件」

`json`-only 的区间被外推到所有规则 ｜ ε 下界被误归因为坍缩源 ｜
错误因果链（称 §6.2 被 type 污染）｜ 0.836 信号未验证是否可移植到默认规则 ｜
渐近退化被用来解释 `layers=2` 的结果。
