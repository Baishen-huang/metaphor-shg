## 2. Problem A：溯源可靠性的 Beta–Bernoulli 形式化

### 2.1 问题陈述

`provenance.py:51` 的 `frame_reliability`：

```python
return RELIABILITY_ONTOLOGY if registered else RELIABILITY_FALLBACK_CAP
#      = 1.0                            = 0.5
```

`docs/inventory/criteria.md §3` 把这类值列入「**取值无实证依据**」清单
（判定标准：无实测标定 + 无消融 + 无文献出处）。本问题的形式化任务：
**给这个 0.5 一个可检验的定义**。

### 2.2 形式模型

**潜变量**。对第 $j$ 层的第 $i$ 条边，定义

$$Z_{ij} = \begin{cases}1 & \text{该边的框架绑定正确}\\ 0 & \text{否则}\end{cases}$$

$Z_{ij}$ 是**不可观测**的（没有人工逐边标注）。把层 $j$ 内的 $Z$ 视为可交换的：

$$Z_{ij}\mid\theta_j \;\overset{\text{i.i.d.}}{\sim}\; \mathrm{Bernoulli}(\theta_j),\qquad
\theta_j \sim \mathrm{Beta}(\alpha_0,\beta_0)$$

$\theta_j$ 就是「第 $j$ 层的框架绑定正确率」——**它正是手拍 0.5 想表达的量**。

**共轭更新（推导）**。给定 $n_j$ 次观测中 $y_j = \sum_i Z_{ij}$ 个为 1：

$$
\begin{aligned}
p(\theta_j\mid y_j) &\propto \underbrace{\theta_j^{y_j}(1-\theta_j)^{n_j-y_j}}_{\text{似然}}
\cdot \underbrace{\frac{\theta_j^{\alpha_0-1}(1-\theta_j)^{\beta_0-1}}{B(\alpha_0,\beta_0)}}_{\text{先验}}\\[4pt]
&\propto \theta_j^{(\alpha_0+y_j)-1}(1-\theta_j)^{(\beta_0+n_j-y_j)-1}
\end{aligned}
$$

这正好是 Beta 核（利用 $B(a,b)=\Gamma(a)\Gamma(b)/\Gamma(a+b)$ 是归一化常数），故

$$\boxed{\;\theta_j\mid y_j \sim \mathrm{Beta}\!\left(\alpha_0+y_j,\;\beta_0+n_j-y_j\right)\;}$$

**后验均值**（Beta 的均值是 $a/(a+b)$）：

$$\boxed{\;\hat\theta_j \;=\; \mathbb{E}[\theta_j\mid y_j] \;=\; \frac{\alpha_0+y_j}{\alpha_0+\beta_0+n_j}
\;=\; \underbrace{\frac{\alpha_0+\beta_0}{\alpha_0+\beta_0+n_j}}_{\text{收缩权重}}\cdot\underbrace{\frac{\alpha_0}{\alpha_0+\beta_0}}_{\text{先验均值}}
\;+\; \underbrace{\frac{n_j}{\alpha_0+\beta_0+n_j}}_{\text{数据权重}}\cdot\frac{y_j}{n_j}}$$

第二行是**收缩估计的标准形式**：$n_j$ 越小，后验均值越靠近先验均值。
这就是「贝叶斯化」在这个问题上的全部内容——**它是收缩，不是别的**。

**后验方差**（用于 §2.5 的可信区间）：

$$\mathrm{Var}[\theta_j\mid y_j]=\frac{(\alpha_0+y_j)(\beta_0+n_j-y_j)}{(\alpha_0+\beta_0+n_j)^2(\alpha_0+\beta_0+n_j+1)}$$

**先验超参由数据拟合**（经验贝叶斯）。$\alpha_0,\beta_0$ 不由手拍，而是最大化
**边际似然**：

$$p(\{y_j\}\mid\alpha_0,\beta_0)=\prod_j \int_0^1 \mathrm{Bin}(y_j\mid n_j,\theta)\,
\mathrm{Beta}(\theta\mid\alpha_0,\beta_0)\,\mathrm{d}\theta
=\prod_j \binom{n_j}{y_j}\frac{B(\alpha_0+y_j,\;\beta_0+n_j-y_j)}{B(\alpha_0,\beta_0)}$$

对 $\log$ 形式用 L-BFGS-B 数值最大化（本实现把强度钳在 $[0.05,1000]$，
并**显式报告是否触界**——触界意味着「先验强度不可识别」，见 §5.4）。

**打分层的消费**。项目用「有下界的乘性折扣」把可靠性送进排序
（`reliability_factor`）：

$$\text{factor}(r)=\text{floor}+(1-\text{floor})\cdot r,\qquad \text{floor}=0.5$$

贝叶斯版即把 $r$ 从「手拍的两档」换成「后验均值 $\hat\theta_j$」：

$$\text{factor}^{\text{Bayes}}(i)=\text{floor}+(1-\text{floor})\cdot\hat\theta_{j(i)}$$

### 2.5 排序评测：贝叶斯化是否带来增益？

632 条 LLM 非构造金标查询，配对 bootstrap（5000 次）：

| 变体 | MRR@10 | Δ MRR | 95% CI | 裁决 |
|---|---|---|---|---|
| baseline（无折扣） | 0.5487 | — | — | — |
| **手拍封顶 0.5/1.0** | 0.5297 | **−0.0190** | **[−0.0306, −0.0075]** | **显著为负 ❌** |
| **Beta 后验（E1）** | 0.5506 | **+0.0019** | [−0.0009, +0.0054] | 与 0 不可分 |
| Beta 后验（E2） | 0.5496 | +0.0009 | [−0.0008, +0.0031] | 与 0 不可分 |
| Beta 后验（E3） | 0.5488 | +0.0001 | [−0.0009, +0.0011] | 与 0 不可分 |
| **纯随机同幅散布（对照）** | 0.5209 | **−0.0278** | **[−0.0491, −0.0066]** | **显著为负 ❌** |

### 2.6 裁决 A：**贝叶斯化不带来排序增益；但手拍值是有害的**

两条结论，必须分开陈述：

**(1) 贝叶斯化无增益，而且理由是数学的。**
后验均值把两个层压到 0.9688–0.9931，**极差只有 0.024**。
乘性折扣 $\text{floor}+(1-\text{floor})\theta$ 的取值因此落在
$[0.9844, 0.9966]$——这是一个**近似常数**的缩放，而
**乘同一个常数不改变任何候选的相对次序**。所以
$\Delta\text{MRR}\approx 0$ 不是「差一点」，而是**结构上必然**。

> 这解释了为什么三个独立证据（E1/E2/E3）给出的 ΔMRR 都是 +0.002 量级：
> 不是证据不够强，而是**后验均值近似常数 ⟹ 折扣是恒等变换**。

**(2) 手拍 0.5 显著有害（−0.0190 MRR，CI 全负），且**不比随机扰动更好**。**
随机散布对照（与手拍封顶**同幅度**、但与相关性完全无关的乘性因子）
给出 −0.0278（CI [−0.0491, −0.0066]，同样显著为负）。
两者的量级**相同**（手拍的伤害甚至略小），因为 LLM 金标下 MRR 量程窄（≈0.55），
任何打乱 top-1 的乘性扰动都会掉分。

> **★ 这一对照是本节的关键**：它把「手拍封顶有害」升级为一个更强的陈述——
> 手拍封顶携带的「可靠性」信息，对排序而言**与随机噪声不可区分**。
> 所以正确的修复动作是**删除这个通道**（或把 `reliability_floor` 设为 1.0），
> 而不是给它加一个更精细的贝叶斯先验。

**(3) 「后验均值恰好接近手拍值」这一预期被证伪。**
任务书预想的负面结果是「后验均值恰好接近 0.5，所以手拍值碰巧对了」。
实测**相反**：后验均值接近 **1.0**（0.97–0.99），手拍的 0.5 **差得很远**。
这是一个比预期更强的负面结果——它同时否定了「贝叶斯化有增益」和
「手拍值碰巧可用」。

> 「对 P1 效应恒为 0（数学上界）」，且 `REPORT_exp-degrade.md §3.2` 记录

## 3. Problem B：`clue` 泄漏 = 选择偏差 / 后验坍缩

### 3.1 问题陈述

`training.py:_build_from_chunks` 的自监督构造：查询 = chunk 原文，
正样本 = 该 chunk **实际抽出**的超边。`feature_auc` 实测
`clue` 单特征 AUC ≈ 1.0（`mathematics.md` M26、`E.1` 表）。

项目的解释是「排序器退化为复读抽取器」，修法是 `build_weak_refine_set`
（用 refine 缓存里被否决的候选当困难负样本）。这个修法是**手拍的**：
没有说明它降低的是哪种量、降低多少才够。

### 3.2 形式模型

三个二值量（对一条候选）：

| 符号 | 含义 |
|---|---|
| $R$ | **目标量**：候选与查询**真相关** |
| $L$ | **标签**：候选是**抽取器产出的那条边**（`produced_by_extractor`） |
| $C$ | **特征**：`clue` 命中（$C=1 \iff \text{clue}\ge 1$，即触发词重合 ≥2） |
| $Q$ | **查询类型**：$Q=1$ 原始触发词查询，$Q=0$ 改写查询 |

**构造性事实（不是假设）**。抽取器 `extractor.extract` 通道一**只在触发词命中时
产出边**（`hit_tokens = [t for t in tokens if t in chunk]`，无命中则循环体不执行）。
因此

$$C=1 \implies L=1 \qquad\text{（恒真，无例外）}$$

实测确认：自监督样本集 3424 条里 $C=1$ 的 90 条**全部** $L=1$：

$$P(L=1\mid C=1)=\frac{90}{90}=1.000,\qquad
P(L=1\mid C=0)=\frac{766}{766+2568}=0.2298$$

**后验坍缩的机制**。用 $L$ 当标签训练时，模型学的是 $P(L=1\mid\cdot)$。
由上面的恒真式，$C$ 对 $L$ 的判别力是**定义使然**：

$$\mathrm{AUC}(C;L)=0.9981\quad\text{（实测）}$$

而**我们真正想要的是** $P(R=1\mid\cdot)$。两者靠什么连接？只有
$P(L=1\mid R=1)=\alpha$ 与 $P(L=1\mid R=0)=\beta$ 这两个**桥接参数**。
当 $\alpha\to 1,\beta\to 0$ 时 $L$ 是 $R$ 的好代理；当 $\alpha\to 1,\beta\to 1$ 时
$L$ 与 $R$ 无关，学 $L$ 就是学噪声。

**条件独立的正式陈述**：

$$C \perp R \mid Q$$

- $Q=1$（原始触发词查询）：$C=1\Rightarrow L=1$，且 $C$ 与 $R$ 的关联被 $L$
  **完全中介**（$C$ 不提供 $L$ 之外的任何 $R$ 信息）；
- $Q=0$（改写查询）：$C\equiv 0$（常数），对 $R$ 的互信息恒为 0。

实测（`bayes_b_selection.py §2`，5449 条 LLM 金标候选对）：

| 量 | 值 |
|---|---|
| `clue` 取值分布 | {0.0: 5436, 0.5: **13**} |
| $C\equiv 0$ 的比例 | **5436/5449 = 0.9976** |
| AUC(clue; $L$) | 0.4987（clue 恒 0 ⟹ 无信息） |
| **AUC(clue; $R$)** | **0.5061**（bootstrap 95% CI [0.5026, 0.5102]） |
| 效应量 AUC−0.5 | **+0.0061**（可忽略） |

> **★ 这就是后验坍缩的直接证据**：在改写查询上 `clue` 是一个**常数**，
> 它对真目标 $R$ 的判别力是 +0.006（等价于噪声）。
> §6.2 报告的 AUC≈1.0 **只**出现在 $Q=1$ 且标签为 $L$ 的设定下。

### 3.3 去偏估计量（推导）

**问题**：能不能从 $L$ 的统计量反推 $R$ 的统计量？能——但只在**边际比例**上。

设 $P(L=1)=p_L$，桥接参数

$$\alpha = P(L=1\mid R=1),\qquad \beta = P(L=1\mid R=0)$$

由全概率公式：

$$p_L = P(L=1) = \alpha\,P(R=1) + \beta\,P(R=0)
= \beta + (\alpha-\beta)\,P(R=1)$$

反解：

$$\boxed{\;\hat P(R=1) \;=\; \frac{\hat p_L - \hat\beta}{\hat\alpha - \hat\beta}\;}$$

**可识别性条件**：$\alpha\neq\beta$（否则 $L$ 不含 $R$ 的信息，分母为 0）。
**方差代价**：由 delta 方法，$\mathrm{Var}[\hat P(R)]\approx
\mathrm{Var}[\hat p_L]/(\alpha-\beta)^2$——**放大 $1/(\alpha-\beta)^2$ 倍**。

**桥接参数从哪来**：refine 缓存给出了 $(L,R)$ 的**四格表**——因为
`batch_refine` 独立地对 `(句子,源域,目标域)` 判定 is_metaphor，
而 $L$ 由「该 key 是否被抽取器产出」决定，两者来源不同。

实测（3189 条候选）：

| | $R=1$ | $R=0$ |
|---|---|---|
| **$L=1$** | 240 | 24 |
| **$L=0$** | 982 | 1943 |

$$\alpha = \frac{240}{1222}=0.1964,\qquad \beta=\frac{24}{1967}=0.0122,\qquad
\alpha-\beta=0.1842$$

$$\hat P(R=1)=\frac{0.0828-0.0122}{0.1964-0.0122}=0.3832$$

### 3.4 非循环验证（★ 这一节是去偏「有效」的唯一证据）

**陷阱**：把四格表代入去偏公式得到「误差 0」是**代数恒等式**，不是验证
（同一张表估 $\alpha,\beta$ 又估 $P(R)$，反解必然精确复原）。

**正确的检验**：留出法——一半估 $\alpha,\beta$，另一半估 $P(L)$ 并检验。
1000 次随机对半折：

| 估计量 | 偏差 | RMSE |
|---|---|---|
| 项目口径（$P(L)$ 当 $P(R)$） | **−0.3007** | **0.3008** |
| **去偏 $\hat P(R)$** | **+0.0021** | **0.0504** |

**★ RMSE 降低 6.0×**（0.3008 → 0.0504）。这是去偏有效性的**非循环**证据。

**代价**：全量估计的 bootstrap 95% CI = [0.3666, 0.4001]，宽度 0.0336
（方差被 $1/(\alpha-\beta)^2 = 29.47\times$ 放大）。

### 3.5 与手拍修法（弱监督）同台对比

| 样本集 | n | 正 | `clue` 取值数 | AUC(clue; $L$) | 95% CI |
|---|---|---|---|---|---|
| 自监督 chunk（原口径） | 3424 | 856 | 3 | **0.9981** | [0.9969, 0.9991] |
| 弱监督 refine（手拍修法） | 3836 | 959 | 3 | **0.9357** | [0.9297, 0.9415] |

弱监督样本构成：`{pos: 959, refine_reject: 1172, random: 1705}`。

**两条路线的机制完全不同**：

| | 手拍修法（弱监督） | 贝叶斯去偏 |
|---|---|---|
| 动作 | **改样本集**：加入同 clue 的负样本 | **不改样本集**：估计并扣掉 $\beta$ |
| 效果 | AUC 0.9981 → 0.9357（−0.0624） | $\hat P(R)$ 偏差 0.3007 → 0.0021 |
| 治什么 | 降低 $C$ 与 $L$ 的确定性 | 修正**总体比例**的偏差 |
| 局限 | 只压到 0.9357，未消除 | 对**逐候选排序**无帮助（需逐候选 $\alpha_i,\beta_i$） |

> **注**：弱监督把 AUC 从 0.998 压到 0.936 之后仍有泄漏——因为它加入的
> 「refine 否决的候选」与正样本**同句同触发词**，但 `clue` 的取值分布
> 仍只有 3 档，$C=1$ 时 $L=0$ 只有 8 条（vs $L=1$ 的 240 条）。
> 手拍修法**降低了泄漏但没有消除**，且没有给出「降到多少才够」的判据——
> 贝叶斯去偏给出的判据是 $\alpha-\beta$ 的大小。

### 3.6 裁决 B：**去偏对「比例」有效（RMSE 6.0×），对「排序」无效**

**(1) 正面结果**：去偏估计量把「$P(L)$ 当 $P(R)$」的 **0.30 偏差**扣到 **0.002**，
RMSE 降 6.0×。这是一个**真实、可复现、非循环**的增益。

**(2) 但增益不在排序上。** 在 by-construction 查询（含触发词，$n=861$，
`clue` 取值 {0.0: 6316, 0.5: 1033, 1.0: 88}）上把 `clue` 权重从 0.4323 置 0：

| 配置 | MRR@10 | Δ MRR | 95% CI |
|---|---|---|---|
| HAND_WEIGHTS（含 clue） | 0.9977 | — | — |
| 去 clue + 重归一化 | 0.9890 | **−0.0087** | [−0.0134, −0.0046] |

而在 632 条改写查询上 `clue` 恒为 0 ⟹ 去 clue **严格 Δ=0（逐位相同）**。

> **★ 结论：`clue` 的统计泄漏与它的排序价值是两回事。**
> 去掉它在含触发词查询上**显著变差**（−0.0087），在改写查询上无变化。
> 所以「删掉 clue 特征」**不是**正确的修法——正确的修法是
> **去偏估计总体指标**（§3.3），并在报告时声明 $\alpha,\beta$。
>
> §6.2 的「排序器退化为复读抽取器」是对**训练集可分性**的正确描述，
> 但它**不等于**「clue 是有害特征」。这一区分是本实验的方法论收益。

**(3) 一个附带发现**：$L$ 是 $R$ 的**弱**代理——$\alpha=0.196$ 意味着
**只有 19.6% 的真相关候选会被抽取器产出**。也就是说自监督标签的
**召回率**只有 19.6%（`REPORT_exp-degrade.md` 记录的开放发现召回边际
贡献 +55.8pp 是同一现象的另一面）。这解释了为什么「$P(L)$ 当 $P(R)$」
会低估 0.30——**自监督标签系统性偏小**。

## 4. Problem C：LLM-as-judge 金标的误差率

### 4.1 问题陈述

项目用 LLM judge 造金标（`llm_cache_judge.json`，571 个问题），
并用 $\kappa=0.965$（跨模型二评）声称金标稳健，但**把金标当精确值**使用。
本问题的形式化任务：给误差率一个后验，并把不确定性传播到 §6.1/§6.2 指标。

### 4.2 形式模型（三层分层模型）

**层 1（条目真值）**：$T_i \sim \mathrm{Bernoulli}(\pi)$，$\pi$ = 相关候选的先验比例。

**层 2（评审误差）**：评审 $j$ 的灵敏度 / 特异度

$$\mathrm{se}_j,\ \mathrm{sp}_j \;\sim\; \mathrm{Beta}(a_0,b_0)\quad\text{(独立同先验)}$$

**层 3（观测）**：

$$Y_{ij}\mid T_i=1 \sim \mathrm{Bernoulli}(\mathrm{se}_j),\qquad
Y_{ij}\mid T_i=0 \sim \mathrm{Bernoulli}(1-\mathrm{sp}_j)$$

**边际似然（单次评审）**：

$$P(Y=1)=\pi\,\mathrm{se}+(1-\pi)(1-\mathrm{sp})$$

### 4.3 可识别性（★ 本问题唯一真正的困难）

**只有同一个条目的两次评审才能约束误差率**——因为 $T_i$ 不可观测，
单次评审的 $Y_{i1}=1$ 既可能是真相关也可能是假阳，无法分离。

在「两次评审同误差率（$\mathrm{se}_1=\mathrm{se}_2=\mathrm{se}$，
$\mathrm{sp}_1=\mathrm{sp}_2=\mathrm{sp}$）+ 给定 $T_i$ 条件独立」下，
**分歧率** $d=P(Y_{i1}\neq Y_{i2})$ 有闭式：

$$
\begin{aligned}
P(Y_{i1}\neq Y_{i2}\mid T_i=1) &= 2\,\mathrm{se}(1-\mathrm{se})\\
P(Y_{i1}\neq Y_{i2}\mid T_i=0) &= 2\,\mathrm{sp}(1-\mathrm{sp})
\end{aligned}
$$

$$\boxed{\;d = \pi\cdot 2\,\mathrm{se}(1-\mathrm{se}) + (1-\pi)\cdot 2\,\mathrm{sp}(1-\mathrm{sp})\;}$$

**对称特例** $\mathrm{se}=\mathrm{sp}=q$ 时 $\pi$ 消掉：

$$d=2q(1-q)\;\Longrightarrow\; q^2-q+\tfrac{d}{2}=0\;\Longrightarrow\;
\boxed{\;q=\frac{1\pm\sqrt{1-2d}}{2}\;}$$

取小根即单次评审错误率。

### 4.4 实测：两次评审配对

项目恰好有两次这样的实验：

| 二评实验 | n | 11 | 10 | 01 | 00 | 分歧率 $d$ | 对称假设下 $q$ |
|---|---|---|---|---|---|---|---|
| 跨模型（glm-4.7） | 113 | 16 | 0 | 1 | 96 | 0.0088 | 0.0044 |
| **换序（同模型，逆序+temp0.4）** | 420 | 63 | 0 | **10** | 347 | **0.0238** | **0.0120** |

$$\Rightarrow\; \text{单次评审错误率上界} \approx \mathbf{1.2\%}$$

**★ 方向性检验（重要的负面发现）**：

| 二评实验 | $n_{10}$ | $n_{01}$ | 二项检验 p |
|---|---|---|---|
| 跨模型 | 0 | 1 | 1.0000（对称） |
| **换序** | **0** | **10** | **0.0020（显著不对称 ⚠️）** |

换序二评的 10 处分歧**全部**是「首评 0、二评 1」——**二评更宽**。
这与项目自己的记录逐字一致（`论文初稿.md §6.5`：「10 处不一致全部为二评更宽」）。

> **★ 方法论后果**：对称假设 $\mathrm{se}=\mathrm{sp}$ **不成立**，
> 所以 $q=(1-\sqrt{1-2d})/2$ 只是**量级参考**，不是无偏估计。
> 更根本的是：**分歧率无法区分「首评漏判」与「二评假阳」**——
> 两种解释给出完全不同的误差方向，而数据不含区分它们的信息。
> 这正是 §4.5 里 $\mathrm{se}$ 与 $\mathrm{sp}$ 区间极宽的原因。

### 4.5 网格后验

对 $(\mathrm{se},\mathrm{sp},\pi)$ 做网格后验（先验 Beta(1,1)，61³ 格点）：

| 参数 | 后验均值 | 95% 可信区间 |
|---|---|---|
| $\mathrm{se}$ | 0.9489 | **[0.8830, 0.9995]** |
| $\mathrm{sp}$ | 0.9930 | [0.9829, 0.9995] |
| $\pi$ | 0.1661 | [0.1370, 0.2030] |

**拟合自洽性检验**：观测阳性率 = 0.1500，模型预测
$\pi\,\mathrm{se}+(1-\pi)(1-\mathrm{sp}) = 0.1635$（一致）。

> **★ $\mathrm{se}$ 的区间宽达 0.117**（[0.883, 1.000]），而 $\mathrm{sp}$ 只有 0.017。
> 这不是采样不足，而是 §4.3 说的**结构性不可识别**：
> 分歧率只约束 $(\mathrm{se},\mathrm{sp})$ 的某个组合，方向无法分开。

### 4.6 传播：§6.1/§6.2 指标的可信区间

**传播方式**：从后验抽 $(\mathrm{se},\mathrm{sp},\pi)$，按**后验预测**
重抽每个候选的真值 $T_i$：

$$P(T=1\mid Y=1)=\frac{\pi\,\mathrm{se}}{\pi\,\mathrm{se}+(1-\pi)(1-\mathrm{sp})}
\quad\text{(PPV)}$$

$$P(T=1\mid Y=0)=\frac{\pi(1-\mathrm{se})}{\pi(1-\mathrm{se})+(1-\pi)\,\mathrm{sp}}$$

400 次重抽 × 632 查询：

| 指标 | 现报（金标精确） | 积分掉金标不确定后 | 95% 可信区间 |
|---|---|---|---|
| **§6.2 人工加权 MRR@10** | **0.5487** | **0.5581** | **[0.5481, 0.5717]** |
| §6.2 自监督 MRR@10 | 0.5449 | 0.5545 | [0.5441, 0.5690] |
| §6.2 人工加权 Hits@3 | 0.6693 | 0.6836 | [0.6678, 0.7022] |
| §6.2 自监督 Hits@3 | 0.6377 | 0.6537 | [0.6376, 0.6749] |
| §6.1 语义通路 Recall@10 | 1.0000 | 1.0000 | [1.0000, 1.0000] |

**★ 关键数字**：$\Delta\text{MRR} = +0.0094$，**区间宽 0.0237**。
即「金标误差」这一不确定性源给 §6.2 的 MRR@10 带来约 **±1.2pp** 的带宽。

**★ 为什么积分后 MRR 升高（而不是降低）？**
噪声模型的净效应是**把漏判的真相关补回金标**：

$$P(T=1\mid Y=1)=0.9641\ \text{(判 1 基本是真)},\qquad
P(T=1\mid Y=0)=0.0101\ \text{(判 0 仍有 1\% 是真)}$$

现报金标**系统性偏小**（漏判 → 金标缺项 → MRR 被低估）。
**这不是「贝叶斯让指标变好」，而是暴露了现报数字的偏差方向。**

**误差假设的敏感性**（每档 200 次重抽）：

| 假设 | 人工加权 MRR@10 | 自监督 MRR@10 | Hits@3（人工） |
|---|---|---|---|
| 金标精确（$\mathrm{se}=\mathrm{sp}=1$） | 0.5487 | 0.5449 | 0.6693 |
| $\mathrm{se}=\mathrm{sp}=0.988$（§4.4 导出的上界） | 0.5521 | 0.5484 | 0.6746 |
| $\mathrm{se}=\mathrm{sp}=0.95$（更悲观） | 0.5592 | 0.5564 | 0.6862 |
| $\mathrm{se}=0.95,\mathrm{sp}=0.99$（漏判多于误判） | 0.5577 | 0.5544 | 0.6831 |

**★ 核心对比「自监督 − 人工加权」**：

| | 现报 | 积分后 | 95% CI |
|---|---|---|---|
| ΔMRR@10 | **−0.0038** | **−0.0036** | [−0.0065, −0.0004] |

**不跨 0** ⟹ 金标不确定性**没有**改变「自监督略差于人工加权」这一结论
（与 `论文初稿.md §6.2` 的 deanchor 结论方向一致）。

### 4.7 先验敏感性：Beta 先验本身可证伪吗？

五档先验，各 150 次重抽：

| 先验 | $\mathrm{se}$ 后验均值 | $\mathrm{sp}$ 后验均值 | $\pi$ 后验均值 | MRR 均值（人工） | MRR 95% CI |
|---|---|---|---|---|---|
| Beta(1,1) 均匀 | 0.9468 | 0.9935 | 0.1670 | 0.5582 | [0.5479, 0.5700] |
| Beta(.5,.5) Jeffreys | 0.9522 | 0.9941 | 0.1666 | 0.5573 | [0.5474, 0.5694] |
| Beta(9,1) 偏向高准确 | 0.9557 | 0.9923 | 0.1649 | 0.5568 | [0.5476, 0.5699] |
| **Beta(1,9) 偏向低准确** | **0.8941** | 0.9800 | 0.1650 | **0.5666** | [0.5529, 0.5843] |
| Beta(19,1) 强偏向高准确 | 0.9651 | 0.9910 | 0.1625 | 0.5555 | [0.5471, 0.5687] |

**★ 极差 = 0.0111**（0.5555–0.5666）。

**对「Beta 先验本身是否不可证伪」的诚实回答**：

- **部分可证伪**：分歧率 $d=0.0238$ 是一个**数据**量，它把 $q$ 的上界
  钉在 ~1.2%，因此**任何**合理先验都会收敛到同一片小误差区域。
  先验不敏感性（极差 0.011）是这个约束的直接后果，不是先验选择的功劳。
- **但模型有一处结构性不可证伪**：$\mathrm{se}$ 与 $\mathrm{sp}$ 的**方向**
  在所有五档先验下都无法从分歧率识别（§4.3/§4.5）。要识别它需要
  **人工标注的第三条评审**（或部分已知真值的锚点）——项目当前没有。
- **因此**：本模型给出的是「金标误差**量级** ≈1.2%」这一结论，
  **不能**给出「误差偏向漏判还是误判」这一结论。§4.6 的
  「现报金标系统性偏小」这一判断**依赖于** $\mathrm{se}<\mathrm{sp}$ 的假设
  （由 §4.4 的方向性检验**弱**支持：二评更宽，但无法确定谁更准）。

### 4.8 裁决 C：**正面 —— 可信区间已给出，且揭示了系统性偏差**

**(1) 给出了可信区间**：§6.2 人工加权 MRR@10 = 0.5581 [0.5481, 0.5717]，
带宽约 ±1.2pp。**这个带宽大于 §6.2 里几个被当作结论的差异**
（例如「自监督 − 人工加权」现报 −0.0038）——即**金标误差是与被测效应
同量级的不确定性源**，报告单点数字而不报区间是不充分的。

**(2) 揭示偏差方向**：积分后 MRR **升高** 0.0094，因为现报金标漏判
（$P(T=1\mid Y=0)=0.0101$）。方向与幅度都可量化。

**(3) 结论稳健**：核心对比「自监督 − 人工加权」在积分后仍不跨 0，
且对先验不敏感（极差 0.011）。**金标不确定性没有推翻任何已上报结论**，
但它给所有 §6.1/§6.2 数字加上了 ±1.2pp 的误差带。

## 5. 诚实局限

### 5.1 三个模型共同的局限

1. **没有人工逐边标注**。A 的 $Z$、B 的 $R$、C 的 $T$ 全都是**代理量**。
   本文件里所有「正确率 0.97–0.99」都是「**LLM 判定为相关**」或
   「**CCL2018 句级标注为隐喻句**」，不是「框架绑定在语言学上正确」。
   代理与真值之间的 gap 无法用本项目现有数据量化。
2. **A 的 E3 是句级而非边级**。$Z$ 是「这条边的框架绑定是否正确」，
   而 CCL2018 标注的是「这句话是不是隐喻句」。一个句子为真隐喻
   并不蕴含其每条边的框架绑定都正确。E3 因此是**弱代理**。
3. **所有 bootstrap 都是查询级重抽**，未对「文档级」相关性做多层结构
   （同一伪文档内的查询共享候选池，独立性不严格成立）。这会使区间
   略微偏窄。

### 5.2 A 特有的局限

4. **「删除可靠性通道」的建议未在本实验中直接验证**。
   本实验验证的是「后验均值 ≈ 恒等变换」（Δ=+0.0019，CI 跨 0），
   以及「手拍封顶有害」（Δ=−0.0190）。「设为 floor=1.0 会更好」
   是从「baseline 优于手拍封顶」推得的，未单独跑 floor=1.0 臂。
   （`REPORT_exp-degrade.md §3.2` 的 floor 全档位扫描支持这一推断。）
5. **先验强度在 2 层分层下不可识别**（E2×reg 与 E3×reg 触界到 1000）。
   这是真实局限，不是数值故障：2 个层、样本量差异大时，边际似然
   倾向「不收缩」。4 层分层（reg_sup）下不触界。

### 5.3 B 特有的局限

6. **去偏只对边际比例有效**。逐候选的 $\alpha_i,\beta_i$ 无法从四格表
   识别（只有一个 $2\times2$ 表）。要做得更细需要**逐候选的两次评审**，
   项目当前没有。
7. **四格表的两侧来源不同质**。$R$ 来自 refine（对 `(句子,源域,目标域)`
   的判定），$L$ 来自「抽取器是否产出该 key」。两者共享上游（同一批候选），
   所以 $\alpha,\beta$ 的独立性**不是**严格的。这会使去偏估计有残余偏差
   （留出法的 +0.0021 偏差可能低估了真实偏差）。
8. **`clue` 的排序价值小但显著**（−0.0087，CI 全负）。本实验没有回答
   「这个贡献是否可被 `sem` 替代」——`HAND_WEIGHTS` 的 `clue` 权重
   0.4323 是学到的，去掉后重归一化把权重分给了 `sem`/`ground_jaccard`。

### 5.4 C 特有的局限

9. **$\mathrm{se}$ 与 $\mathrm{sp}$ 的方向不可识别**（§4.3/§4.5）。
   这是本问题最严重的局限：模型能说「误差 ≈1.2%」，**不能**说
   「误差偏向哪一侧」。§4.6 的偏差方向结论依赖额外假设。
10. **两次评审不是同一 judge 的重复**。跨模型二评（glm vs deepseek）
    是**两个不同的 judge**，其误差率未必相同；换序二评虽同模型但
    temperature 从 0 改到 0.4，也不是严格重复。所以「两次评审同误差率」
    这一模型假设**是近似的**。
11. **对称误差模型被数据证伪**（§4.4 方向性检验 p=0.0020）。
    §4.5 的网格后验不依赖对称假设，但 §4.4 的 $q\approx1.2\%$ 依赖它，
    只能读作量级参考。
12. **$\kappa=0.965$ 与误差率是两回事**。本实验没有推翻 $\kappa$，
    而是指出 $\kappa$ 高**不蕴含**误差率低（一致可以是「一起错」）。
    这是对项目表述的一个方法论澄清，不是对数据的否定。

## 6. 附带发现：一个未披露的全局状态污染（★ 影响已有数字）

### 6.1 现象

本 harness 的第一版把建好的图**序列化缓存**以加速迭代。缓存命中时，
`hand_weighted` 的 MRR@10 是 **0.5241**；缓存未命中（重新建图）时是
**0.5487**。**同一个脚本、同一份缓存数据、同一份代码**，只因为走了
pickle 缓存，结果差 **2.5pp**。

### 6.2 根因

`metaphor_graph/llm_ontology.py:349-355`：

```python
# 不做这一步的话，新建的 DISCOVERED::* 映射不在 TYPE_CONSTRAINTS 里，
TYPE_CONSTRAINTS.setdefault(spec.source_type, [])
if spec.mapping_type not in TYPE_CONSTRAINTS[spec.source_type]:
    TYPE_CONSTRAINTS[spec.source_type].append(spec.mapping_type)
```

`TYPE_CONSTRAINTS` 是 `ontology.py:88` 的**模块级 dict**，而
`CascadeOntology.type_valid`（`:409`）直接读它：

```python
return mapping_type in TYPE_CONSTRAINTS.get(source_type, [])
```

**实测规模**：

```
TYPE_CONSTRAINTS 总条目：构建本体前 23 → 构建后 1104（+1081）
```

**后果**：`build_llm_ontology()` 的**副作用**是给全局 dict 注册 1081 个
`DISCOVERED::*` 映射类型。而 `type_reliability_of`（`ontology.py:422`）
对已登记框架调 `type_valid`——如果这个副作用没被施加，
**自举框架的 `type` 特征会返回 0.0 而不是 1.0**（`type_reliability_of`
的 `TYPE_RELIABILITY_INVALID` 分支），整维漂移。

复现验证（`bayes_a_reliability.py` 的自校验命令）：

```python
from metaphor_graph.ontology import TYPE_CONSTRAINTS as TC
n0 = sum(len(v) for v in TC.values())          # 23
from metaphor_graph.evaluate_fullcorpus import build_replay_ontology
ont, _ = build_replay_ontology()
n1 = sum(len(v) for v in TC.values())          # 1104
```

### 6.3 影响面

任何**绕过 `build_llm_ontology()` 直接构造/反序列化本体**的代码路径都会中招：

| 路径 | 是否受影响 |
|---|---|
| `evaluate_fullcorpus` / `evaluate_llmgold` 的 CLI（每次新建本体） | 否 |
| 把本体 pickle 缓存后复用（本 harness 的第一版） | **是（−2.5pp MRR）** |
| 从 `ontology_default.json` 反序列化后直接 `CascadeOntology(...)` | **是** |
| 单测里手工构造 `CascadeOntology` | **是**（除非恰好不用 `type` 特征） |

### 6.4 为什么这值得单独记录

**(1) 它是一个「静默降级」**：不抛异常、不告警，只是 `type` 特征从 1.0 变 0.0。
项目自己的 `README §7.2` 记录了同类教训（「静默降级曾产出看似正常实则全错的结果」），
但这一处**没有被识别为同类问题**。

**(2) 它使「同一个口径」在不同调用路径下给出不同数字**。这与
`docs/inventory/mathematics.md §E.5`（口径冲突型）是同型缺陷，但
**更隐蔽**——因为它不是两个函数各写一份定义，而是**一个函数依赖全局可变状态**。

**(3) 它解释了本项目的一个已知现象**：`mathematics.md` 记录
`type` 特征「无 ontology 时 3 维恒 0」「取值 {1.0: 7437} 全为 1.0」
等退化现象。本发现提示：**`type` 维的取值依赖调用顺序**，
任何「先建本体 vs 后建本体」的差异都会体现在这一维上。

**修复方向**（本文件只报告，未修改代码）：把 `DISCOVERED::*` 的注册
从「构造本体的副作用」改成「本体对象的成员」（例如让 `type_valid` 优先
查 `self._extra_mappings`），或至少在模块级提供
`register_discovered_types(ont)` 供反序列化路径显式调用。

> **本 harness 的应对**：`_bayes_common.build_graphs()` 在**每次**返回缓存时
> 都重新调用 `_fresh_ontology()` 以重新施加该副作用，并且
> `verify_against_reference()` 在**缓存命中后再次**执行逐位比对（§1.2）。
> 这是本 harness 唯一一处「为了绕过项目缺陷而写的防御代码」。

## 7. 「贝叶斯化是否带来增益」总结

| 问题 | 贝叶斯化带来增益？ | 数字 | 真正的收益 |
|---|---|---|---|
| **A 溯源可靠性** | ❌ **否** | 后验均值 ΔMRR **+0.0019**（CI 跨 0）；手拍封顶 ΔMRR **−0.0190**（CI 全负），随机对照 **−0.0278** | **定位了手拍值有害**（不是「不精确」而是「与噪声不可区分」）；证明正确动作是**删除通道**而非精修先验 |
| **B clue 泄漏** | ⚠️ **部分** | 去偏 RMSE **0.3008 → 0.0504（6.0×）**；但排序上 ΔMRR **−0.0087**（去 clue 更差） | **去偏估计量**对总体比例有效且非循环验证；证明「删特征」是错的修法 |
| **C 金标误差** | ✅ **是** | MRR@10 **0.5487 → 0.5581 [0.5481, 0.5717]**；带宽 ±1.2pp；先验极差 **0.0111** | 给出可信区间；揭示现报金标**系统性偏小**（漏判）；澄清 $\kappa$ 高 ≠ 误差低 |

**三条可复用的教训**：

1. **「贝叶斯化」的本质是收缩**（A）。当所有层的 MLE 都接近 1 时，
   收缩把后验均值压成一个近似常数 ⟹ 乘性折扣退化为恒等变换 ⟹
   **排序指标必然无变化**。这不是「先验选得不好」，是数学必然。
   要判断贝叶斯化是否可能有用，先看**层间 MLE 的极差**是否够大。
2. **统计泄漏 ≠ 特征有害**（B）。$C$ 与 $L$ 的确定性关联是**构造使然**，
   但它不影响 $C$ 对 $R$ 的（微弱的）排序价值。正确动作是
   **去偏估计总体指标**，不是删特征——删特征实测**显著变差**。
3. **可识别性先于推断**（C）。分层模型看起来很美，但
   $\mathrm{se}$ 与 $\mathrm{sp}$ 从分歧率**结构上不可识别**。
   在写模型之前先问「数据里有能识别这个参数的量吗」——
   本项目的数据只能给误差**量级**，给不了**方向**。
