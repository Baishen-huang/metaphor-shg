## 1. T1/T2：行和归一与特征值实性

### 1.1 行和为 1（活节点）

**陈述**：对任意超图，`Σ_j S_ij = 1` 当节点 `i` 的度 > 0；孤立节点整行为 0。

**证明（三行）**：
```
S = D_v⁻¹ · B,  B = H D_e⁻¹ Hᵀ
(B·1)_i = Σ_e H_ie (1/|e|) Σ_w H_we = Σ_e H_ie (1/|e|)·|e| = Σ_e H_ie = D_v(i)
∴ (S·1)_i = D_v(i)⁻¹ · D_v(i) = 1        （D_v(i) > 0）
```
孤立节点：`D_v(i) = 0` → `D_v⁻¹` 被零保护 → 整行为 0（不满足行和 1，这是**设计如此**）。

**数值验证**：27 个图（含空图、单边、路径、双分量、孤立点、空超边、自环、平行边、
随机图 V=30…200、真实图 V=61/31/886/2825）：

| 指标 | 结果 |
|---|---|
| `B_rowsum_live_maxdev`（活节点行和偏差） | **≤ 2.2e-16**（机器精度） |
| `B_rowsum_iso_maxabs`（孤立节点行和） | **恰为 0.0**（27/27） |

### 1.2 特征值全实

**陈述**：`S` 相似于对称矩阵 `D_v^{-1/2} B D_v^{-1/2}`，故特征值全实。

**证明**：`S = D_v⁻¹ B`，故 `D_v^{1/2} S D_v^{-1/2} = D_v^{-1/2} B D_v^{-1/2}`，
右端对称（`B` 对称），故 `S` 与对称矩阵相似。

**数值验证**：`A_similarity_maxdiff` ≤ **3.3e-16**；
`A_eig_real_maximag`（特征值虚部最大值）≤ **4.8e-16**（27/27）。

> 注：`M` **不对称**（项目 README 已记录），但**相似于**对称矩阵，故仍全实谱。

## 2. T3/T4：谱半径、零空间与 ε-阻尼

### 2.1 ρ(S) = 1 与零空间维数

**陈述**：
- `ρ(S) = 1`（当图非空；空图 `ρ(S) = 0`）
- `dim ker(S) = V − rank(H)`

**证明要点**：行随机 ⟹ `1` 是特征值且 `ρ ≤ 1`；`S·1 = 1` 给下界 ⟹ `ρ = 1`。
零空间维数：`S = D_v⁻¹ H D_e⁻¹ Hᵀ`，`D_v⁻¹` 在活节点上可逆，
故 `ker(S) = ker(Hᵀ)` ⊕ （孤立节点），`dim = V − rank(Hᵀ) = V − rank(H)`。

**数值验证（决定性）**：`D_dim_ker_S` 与 `D_V_minus_rankH` **27/27 逐图精确相等**：

| 图 | V | E | dim ker(S) | V−rank(H) | ρ(S) |
|---|---|---|---|---|---|
| empty_graph | 4 | 0 | 4 | 4 | 0.0 |
| doc_project | 61 | 30 | 40 | 40 | 1.0 |
| doc_relationship | 31 | 17 | 20 | 20 | 1.0 |
| ccl200 | 886 | 560 | 353 | 353 | 1.0 |
| ccl1100 | 2825 | 2257 | 929 | 929 | 1.0 |

**意义**：这解释了"无源项扩散塌缩"的**代数根源**——`ker(S)` 维数很大
（ccl1100 上 929/2825 ≈ 33%），这些方向在传播中被**完全湮灭**。

### 2.2 mult(λ=1) = 活连通分量数

**数值验证**：`C_match = True`（27/27），`C_live_components` 逐图匹配
（doc_project 5 个分量、ccl1100 168 个）。

**意义**：这**定量确认**了项目此前"收敛到分量平稳分布"的观察——
平稳空间维数恰等于连通分量数，故每个分量内所有节点收敛到同一向量。

### 2.3 ε-阻尼：ρ(M_ε) = 1 − ε/2

**陈述**：`S_ε = (1−ε)S` 时 `ρ(S_ε) = 1−ε`，`ρ(M_ε) = 1 − ε/2`。

**数值验证**（ccl200 / ccl1100 / doc_project 三图 × ε∈{0, 0.1, 0.2}）：

| ε | ρ(M_ε) 实测 | 预测 1−ε/2 |
|---|---|---|
| 0.0 | 1.0000000000000004 | 1.0 |
| 0.1 | 0.9500000000000004 | 0.95 |
| 0.2 | 0.9000000000000004 | 0.9 |

**全部命中**。这给出**严格次随机条件的代价**：ε 每增加 0.1，
`ρ(M)` 只降 0.05 —— 即阻尼对谱半径的影响是**半效**的。

**对 RiverMemo 对照的意义**：外部系统要求 `Σ_j P_ij < 1` 严格。
本项目实测 `cond(I−M)` 在 ε=0 时达 **3.9e17**（ccl1100），
即 `(I−M)` **数值上不可逆**——这正是需要 ε 的**工程理由**，
且 ε=0.1 已把 `cond` 改善到可用范围。

## 3. T5：收敛速率的闭式定理

### 3.1 误差的精确表达式

**陈述**：驱动迭代 `u_k = (1−α)X₀ + αM u_{k−1}` 满足

```
u_k − u* = (αM)^k (X₀ − u*)
```

**证明**：`u_k − u* = αM(u_{k−1} − u*)`，递推即得。

**数值验证**：42 个 (α,k) 组合，maxdiff = **5.8e-16**。

**推论（速率定理）**：误差按 `(α·μ₂(M))^k` 衰减，其中 `μ₂` 是 `M` 的第二大特征值模。

**数值验证**（α·μ₂ 预测 vs 谱和拟合）：

| α | α·μ₂ 预测 | 拟合率 | 相对误差 |
|---|---|---|---|
| 0.300 | 0.294798113 | 0.293857085 | −9.4e-4 |
| 0.500 | 0.491330188 | 0.490471775 | −8.6e-4 |

（拟合率略低于预测，因有限步内高阶模态尚未完全衰减——方向正确。）

### 3.2 源项不改变平稳分量

**陈述**：`Πu* = ΠX₀`，其中 `Π` 是到平稳空间的投影。

**数值验证**：maxdiff = **3.5e-15**。

**意义**：源项只改变**瞬态**，不改变**稳态**——这解释了为什么加源项后
`metaphor_coherence` 保留了源身份（瞬态携带源信息），而长期行为仍由分量结构决定。

## 4. T6：`layers=2` 余弦的精确预测（本方向最有价值的成果）

### 4.1 问题

项目此前报告 `layers=2` 时同分量平均余弦 = **0.383**（实测），
但从未能**预测**它——只能测。这导致一个悬而未决的问题：
"0.950 的 H4 判别力是否来自算子退化？"

### 4.2 预测公式

无源项迭代 `X_k = M^k X₀`，同分量内两节点 `i,j` 的余弦为

```
cos_k(i,j) = (M^k X₀)_i · (M^k X₀)_j / (‖(M^k X₀)_i‖ ‖(M^k X₀)_j‖)
```

对 `k=2` 可直接计算。脚本 `t2_convergence.py` 给出**解析式**（`pred_exact` 列）。

### 4.3 验证（预测 vs 实测，逐 k）

| k | 实测 within_cos | **解析预测** | 偏差 |
|---|---|---|---|
| 0 | 0.033537584272241405 | 0.03353758427224148 | 7.9e-16 |
| **2** | **0.38300320937497484** | **0.383003209374975** | **5.6e-16** |
| 5 | 0.648543978738464 | 0.6485439787384644 | 4.7e-16 |
| 10 | 0.8035495663193399 | 0.8035495663193399 | 5.0e-16 |
| 50 | 0.9635365626556016 | 0.9635365626556016 | 1.4e-15 |
| 500 | 0.9999999940074278 | 0.9999999940074278 | 1.3e-14 |

**`k=2` 的 0.383003 被精确预测（偏差 5.6e-16）。**

### 4.4 对 H4 争议的裁决

这条预测**独立支持**了 `exp/dynamics` 的结论：

- 若"0.950 是算子退化造成的"，则 `layers=2` 时应已接近退化（余弦 → 1）；
- 但**闭式预测与实测都给出 0.383**，远离 1.0；
- 且 `μ₂(M) = 0.9827`，衰减很慢 —— 要到 k≈500 才达 0.99999。

**故"退化"在 `layers=2` 处不成立**，与 dynamics 分支的
"完美同分量指示器上限仅 0.800 < 0.950"独立互证。

**另一个副产品**：脚本还给出**首次预测**（`pred_fo`）与**二阶预测**（`pred_2m`）列，
显示一阶近似在 k=2 时误差较大（0.120 vs 0.383），说明**必须用精确式**，
不能用简单指数近似。

## 5. T7：重复成员致两种实现分歧

### 5.1 现象

`_conv` 按 `he_members`（List）遍历，重复成员**计两次**；
`propagation_matrix` 用 Boolean 关联矩阵，重复**无法表示**。

### 5.2 规模（实测）

| 本体 | 含重复成员的边 | 占比 |
|---|---|---|
| `ontology_default.json` | 295 / 2177 | 13.6% |
| `llm_ontology_train.json` | 303 / 2185 | 13.9% |
| 真实建图（ccl200） | 36 / 560 | 6.4% |
| 真实建图（ccl1100） | 173 / 2257 | 7.7% |

**不是理论边角** —— 7.7% 的边会触发分歧。

### 5.3 修正公式

正确的矩阵形式应使用**带重数的关联矩阵** `H̃`（`H̃_ve = 该节点在该边中的出现次数`）：

```
S_correct = D_v⁻¹ H̃ D_e⁻¹ H̃ᵀ
```

而非 Boolean 版本。`t5_duplicates.py` 给出逐图对比（`t5_duplicates.csv`）。

> **这是本次数学探索发现的一个真实代码缺陷**：
> `propagation_matrix()` 的 docstring 声称与 `_conv` "逐元素等价"，
> 但含重复端点时不等价（实测 maxdiff 0.042，见 `docs/inventory/mathematics.md`）。

## 6. 诚实边界

1. **T1–T4 是"有限图上验证"，不是 Lean 证明。** 27 个图覆盖了空图、退化图、
   随机图、真实图，但**不构成全称命题的证明**。
   Lean 侧：`lean/MetaphorSHG/Core.lean` 已验证**代数骨架**（9 定理，
   交换律/分配律/零保护），谱定理本身仍在 `Spectral.lean` 草稿（21 `sorry`）。
2. **T5 的"拟合率略低于预测"未深究**（差 8.6e-4）。原因是有限步高阶模态，
   但未给出定量修正。
3. **T6 的预测在真实句向量下未复测**（本项目 embed 缓存覆盖 81.9%）。
4. **`ε` 的最优取值未定**。本报告给出 `ρ(M_ε) = 1−ε/2` 与 `cond` 的定量关系，
   但"ε 取多少最好"依赖下游指标，需实验确定（`t4_epsilon.py` 有扫描框架）。
5. **未验证 `ρ(S)=1` 在浮点下的稳定性**：所有实测值都是 1.0 ± 1e-15，
   但大图（V=2825）的 `ρ` 计算本身有数值误差，未做区间分析。
