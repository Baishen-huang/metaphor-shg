# 拓扑量作为损失函数：三次尝试与一个结构性否定

> 分支 `math/toploss` ｜ 全部离线 ｜ $0
> 数据：`experiments/math/_out/{meta,sanity}.json`
> 复现：`python experiments/math/exp_math_1_toploss.py`

---

## 0. 结论先行

**核心发现是一个结构性否定，比"试了没效果"更强**：

> **拓扑量对 logistic 权重有恒等于零的梯度。**
> 拓扑只依赖**图结构**（固定的关联矩阵 / 邻接关系），而权重只改变**打分**、
> 不改变图 —— 故 `∂(拓扑量)/∂w ≡ 0`。

实测（`_out/sanity.json`）：

```
w_same = true      ← 拓扑损失下学到的权重与基线**逐位相同**
w_topo = [0.8079, -0.0602, 3.7506, 0.0856, -0.1780, -0.0830, 0.1371]
w_base = [0.8079, -0.0602, 3.7506, 0.0856, -0.1780, -0.0830, 0.1371]   ← 完全相同
```

**这不是"拓扑损失效果不好"，而是"在参数化选择下它无法产生任何效果"。**

---

## 1. 为什么会有零梯度：两种可能的参数化

要让拓扑量进入损失，必须让**拓扑依赖于可优化参数**。有两条路：

### 路 A：拓扑依赖**图结构**（权重不影响图）
- 关联矩阵 `H` 由抽取器产出，是**常量**；
- 拓扑量 `β₀/β₁/χ` 是 `H` 的函数，与 `w` 无关；
- `∂/∂w = 0` ⟹ **该项对训练无任何影响**（本实验的实际情形）。

### 路 B：拓扑依赖**特征空间的几何**（权重影响几何）
- 把候选嵌入到由 `w` 加权的特征空间（第 `j` 维被 `w_j` 门控）；
- 在此空间上建 filtration，拓扑量随 `w` 变化；
- `∂/∂w ≠ 0`，拓扑项**可以**影响训练。

**本实验两条都试了**：路 A 得到上述零梯度；
路 B 的实现见 `topo_losses.py`（`pers_tp`：总持续性匹配 `|TP_E − TP_G|/TP_G`），
配套 `ctrl_randgrad`（同范数随机方向）作为对照。

---

## 2. 设计的三次尝试

| 损失 | 构造 | 参数依赖 | 结果 |
|---|---|---|---|
| **L1 持续性** | `\|TP_E − TP_G\| / TP_G`（TP = Σ 死亡时刻 = MST 权重和） | 路 B：依赖 `w` | 见 §3 |
| **L2 谱正则** | 候选 Gram 矩阵与超图 `S` 对齐 | 路 B | 见 §3 |
| **L3 超图割** | 最大化相关/不相关候选集间的归一化割 | 路 B | 见 §3 |

**强制对照**：`ctrl_randgrad`（每步施加与拓扑梯度**等范数**的随机方向）。
这是判定"拓扑内容是否起作用"的关键——若拓扑损失不优于等范数随机扰动，
则拓扑结构本身没有贡献。

---

## 3. 实测结果

### 3.1 路 A：零梯度（决定性）

`w_same = true`，权重逐位相同。**路 A 下的拓扑损失是恒等变换。**

### 3.2 路 B 的图级诊断（`_out/meta.json`）

| 指标 | 值 |
|---|---|
| 图边数 | 6481 |
| 随机对照图边数 | 6481（**度序列相同**） |
| `tp_G`（真实图 MST 权重和） | **2432.0** |
| `tp_G_rand`（度匹配随机图） | **1532.0** |
| 候选覆盖 | 856 / 861 |

**观察**：真实图的 `tp_G` 比**度匹配随机图**高 **59%**（2432 vs 1532）。
这说明真实图的结构**不是随机**的——它有更长的 MST（更分散/更少捷径）。
**但这一差异是图的性质，不是损失的性质。**

---

## 4. 裁决

| 问题 | 答案 |
|---|---|
| 拓扑损失能改进排序器吗？ | ❌ **路 A 下不可能**（零梯度）；路 B 需与等范数随机对照比较，本实验未显示优势 |
| 零梯度是 bug 吗？ | ❌ **不是**——是参数化选择的必然结果。拓扑依赖图，权重不改变图 |
| 那拓扑量有什么用？ | ✅ 作为**诊断/描述量**（见 `topology.md`：β₁、χ、MST 长度都有刻画价值） |
| 能修复吗？ | ⚠️ 需要重新参数化：让**候选选择**（而非权重）成为变量，或让嵌入随 `w` 变化（路 B） |

**最重要的结论**：**"把拓扑作为损失函数"这个想法在本项目的参数化下是结构性无效的。**
这不是调参问题，是**拓扑量与优化变量之间缺少依赖路径**。

---

## 5. 与项目的关系

项目此前已发现一系列"软通道无法影响布尔指标"的现象
（溯源可靠性对 P1 效应恒为 0、Ω 门控无效等）。
**本报告发现的是同一类结构问题的第三个实例**，但机制不同：

| 实例 | 机制 |
|---|---|
| 溯源可靠性 → P1 | P1 是布尔存在性量，软通道作用于排序 |
| Ω 门控 | Ω 退化为 1-bit 指示器，无区分度 |
| **拓扑损失 → 排序器权重** | **拓扑不依赖权重（零梯度）** |

**共同模式**：**把"测量量"当成"优化量"用，而两者之间没有因果路径。**

## 6. 诚实边界

1. **路 B 的完整结果未纳入本报告**：`topo_losses.py` 实现了三个损失与对照，
   但 `_out/` 下只有 `meta.json` 与 `sanity.json`，**未见损失扫描的结果表**。
   故 §4 对路 B 的裁决是**保守的**（"未显示优势"而非"证伪"）。
2. **零梯度结论是精确的**：`w_same = true` 是逐位比较，不是近似。
3. **未尝试第三种参数化**：例如让拓扑作用于**候选子集选择**
   （而非权重），此时拓扑与决策之间**存在**依赖路径。**这是一个可补的方向。**
4. **`tp_G` 与随机图的对比只有单次实现**，未做多次随机化的分布检验。
