## 0. 结论先行（TL;DR）

| 待检命题 | 裁决 | 关键数字 |
|---|---|---|
| Ω 只读查询（对候选池不变） | ✅ **成立**（结构性 + 实测） | 632 条查询 × 4 种候选池扰动（打乱/半量截断/空池，110 文档全跑）→ **0/632** 变化 |
| 改写型 Ω 系统性低于重叠型 | ⚠️ **成立但效应中等、且被 0 块主导** | AUC=0.3493（95%CI [0.325, 0.374]）、Cliff's δ=−0.301、Cohen's d=−0.502、MWU p≈0、配对 Wilcoxon p≈0 |
| 低 Ω 预测级联通路失败 | ⚠️ **partially / 且近乎同义反复** | 全样本 AUC(成功>失败)=0.941，但**去掉 Ω=0 的 518 条后 AUC=0.589（95%CI [0.474, 0.703]，含 0.5，MWU p=0.163）→ 无区分力** |
| Ω 比「触发词命中数」更有信息 | ❌ **否** | Spearman ρ(Ω, n_seed)=**0.9949**；Ω>0 ⟺ n_seed≥1 逐条一致率 **632/632 = 100%**；预测「通路非空」的一致率两者都是 0.8956 |
| Ω 门控优于现有 `if not agg` 判据 | ❌ **否，严格更弱** | Ω 门控漏掉 66 条「有触发词但通路仍空」的查询；现有判据全部拦下 |
| Ω 的三个分量在本基底上都有用 | ❌ **Ω_N 是死分量** | 生产本体 758 个级联中 **752 个（99.2%）成员共享同一目标域** → 涌现恒为空集；Ω_N>0 仅 9/632（改写型） |
| 「改写型 82% collapsed」是基准构造的产物 | ❌ **不是**（反直觉，但数据不支持构造性解释） | 被红线剔除的 226 条 Ω=0 占比 77.0% vs 保留的 632 条 82.0%，AUC 仅 0.5255；自然文本对照：CCL2018 原句同样 62.3% collapsed |

**一句话**：Ω 可以**被计算**（"能测"），且它的低值**确实与**级联通路失败**共现**；但在本项目的隐喻基底上，Ω 相对「查询有没有命中任何一个触发词」这个 **1-bit 指示器**几乎没有额外信息量，而那个 1-bit 指示器与级联通路是否为空是**代码结构的定理等价**。因此 Ω 目前**不构成对 0.042 失败的机制性解释**，也不提供现有判据之外的工程动作。分离现象本身是真实的（改写型 82% collapsed vs 自然文本 21.8%–62.3% collapsed），但它是「本体触发词词表覆盖不足」的投影，不是「改写破坏了隐喻连贯性」的度量。

## 1. Ω 的定义（如实现）

模块：`metaphor_graph/observability.py`（新增，约 300 行）
导出：`__init__.py` 已挂 `QueryObservability / ObservabilityMeter / measure / matched_triggers / activated_structure / normalized_entropy / geometric_mean / regime_of / EPS / SINGLE_FLOW_ENTROPY / SPARSE_MAX`

### 1.1 三个分量 + 几何平均 + 观测完备度

```
Ω_E  edge activation = min(1, |点亮的框架| / |种子触发词|)          clip [0,1]
Ω_N  emergence       = min(1, |级联涌现目标域| / |种子触发词|)      clip [0,1]
                       其中「涌现目标域」= 沿级联取成员框架后的目标域集合
                       − 直接命中框架自身的目标域集合
Ω_F  flow entropy    = H(激活权重分布) / log2(n)     （权重 = 框架被几个触发词命中）
                       无正流量 → 0；单条正流量 → 0.5（有限值）；n>1 → 归一化熵
Ω_geo = (Ω_E · Ω_N · Ω_F)^(1/3)      各分量带 ε=1e-3 下界
Ω     = Ω_geo × 观测完备度           完备度 = 查询中被触发词覆盖的字符占比
Ω ≡ 0                                当且仅当 无触发词命中 或 无框架被点亮（特判，不走 ε 下界）
```

regime：`collapsed`（Ω=0 或无框架）/ `sparse`（Ω < 0.5）/ `dense`（Ω ≥ 0.5）。

**ε 下界的理由**（参考设计的几何平均合成）：几何平均是「与门」式合成，任一分量取 0 会把 Ω 钉死为 0，Ω 就退化成单分量指示器。ε 下界让「某分量很低」表现为「Ω 很小」而不是「Ω=0」，保留序信息。例外是完全无激活——此时 Ω 必须严格为 0。

**观测完备度的理由**：参考设计的 observation-completeness 因子。同一个 Ω_E=1.0，长改写句里偶然夹一个触发词（完备度≈0.05）与短查询整句都是触发词（完备度=1.0）不应等价。

### 1.2 查询侧不变式：由 API 形状保证，而非实验发现

`measure(query, ontology)` 的签名里**没有** `shg` / 候选边 / 检索结果 / 排序器。Ω 读的只有「查询字符串」与「本体（`ontology_default.json` 的框架/级联/触发词表）」。

因此「Ω 对候选池不变」是**结构性**成立的。测试把它钉成回归护栏，防止后来者为了刷指标把候选信号混进来：

- `TestQueryObservability.test_omega_invariant_to_candidate_pool` —— 打乱/半量截断/清空候选池（3 个随机种子 + 空池），Ω 的 `to_dict()` 逐位相同；
- `test_measure_signature_has_no_candidate_argument` —— 反射检查签名里不得出现 `shg/edges/candidates/retriever/chunks/ranked/result/scorer`。

**实验级全量验证（实验 2【A】）**：对 632 条改写查询，逐文档构造 4 种打乱×半量截断 + 空池候选池并实际调用 `cross_domain_retrieve`（触碰候选侧），再重测 Ω：

```
扰动后 Ω 变化条数 = 0/632     → 不变式成立
```

### 1.3 触发词口径与级联通路逐字对齐

`matched_triggers` 用 `[t for t in ont._trigger_index if t in query]`，与 `RetrievalEngine.cross_domain_retrieve`（`retrieval.py:124`）**逐字同口径**。这是 Ω 与级联通路可比较的前提，有测试护栏 `test_trigger_matching_same_as_cascade_path`。

### 3.2 检验与效应量

| 统计量 | 值 |
|---|---|
| Mann-Whitney U（独立样本，并列修正） | U=139514.5, z=−11.478, **p ≈ 0** |
| Wilcoxon 符号秩（配对，同一查询对象） | z=−13.387, **p ≈ 0**, n_nonzero=331 |

**分离方向成立、统计显著、效应量中等（δ≈−0.30）**。bootstrap CI 不含 0.5，排除偶然。

### 3.3 分量分解：分离来自哪一分量

| 分量 | 改写型 mean | 重叠型 mean | 差 | AUC |
|---|---|---|---|---|
| Ω_E 边激活 | 0.1804 | 0.4161 | −0.2358 | 0.3821 |
| Ω_N 涌现 | 0.0142 | 0.0514 | −0.0372 | 0.4810 |
| Ω_F 流量熵 | 0.1123 | 0.3315 | −0.2191 | 0.3691 |
| **观测完备度** | 0.0311 | 0.3876 | **−0.3564** | **0.3450** |
| Ω_geo | 0.0266 | 0.0795 | −0.0529 | 0.3688 |

分离主要由**完备度因子**（AUC 0.345，最偏离 0.5）与 Ω_E/Ω_F 贡献；**Ω_N 的 AUC=0.481 几乎无分离**（见 §6.1）。

### 3.4 分离的稳健性：控制长度后仍在

完备度因子使 Ω 随查询长度系统性下降（改写型 13.5 字 vs 重叠型 2.5 字），这是明显的混杂。两项控制（实验 5【L】）：

| 控制方式 | 改写型 | 重叠型 | AUC | MWU p |
|---|---|---|---|---|
| (a) 只用 Ω_geo（剥离完备度） | mean 0.0266 | mean 0.0795 | 0.3688 | ≈0 |
| (b) 重叠型用中性填充补长到改写型长度分布（均 13.5 字） | mean 0.0051 | mean 0.0126 | 0.3742 | ≈0 |

→ **补长后分离仍存在**，说明主因是「有没有触发词命中」，长度只通过完备度因子**放大**差距，不是唯一来源。

## 4. 低 Ω 是否预测级联通路失败？（实验 1【3】+ 实验 3）

### 4.1 表面结论：是

```
改写型级联通路成功率（Hits@10）= 27/632 = 0.0427
成功组 Ω mean=0.0192 median=0.0133 (n=27)
失败组 Ω mean=0.0045 median=0.0000 (n=605)
AUC(成功 > 失败) = 0.9409
点二列 r = 0.1079, p = 6.6e-3;  Spearman ρ = 0.4608, p ≈ 0
```

### 4.2 关键控制：去掉 0 块后**区分力消失**

518 条 Ω=0 的查询里，级联通路成功的**恰好 0 条**。因此上面的 AUC=0.941 完全由「Ω=0 vs Ω>0」这一个台阶撑起来。只看 Ω>0 的 114 条：

```
Ω>0 子集 n=114，成功率 0.2368
  点二列 r = −0.0848  p = 0.370       ← 无显著
  Spearman ρ = +0.1316 p = 0.163      ← 无显著（且与点二列符号相反）
  AUC(成功>失败) = 0.5892, 95%CI [0.4740, 0.7026]   ← 含 0.5
  MWU p = 0.163
成功组 Ω mean=0.0192 (n=27) | 失败组 Ω mean=0.0311 (n=87)   ← 失败组 Ω 反而更高
```

按 Ω 分箱的成功率**不单调**（反向）：

| Ω 区间 | n | 成功率 |
|---|---|---|
| (0.00, 0.05] | 105 | 0.2476 |
| (0.05, 0.15] | 6 | 0.1667 |
| (0.15, 0.30] | 1 | 0.0000 |
| (0.30, 0.50] | 2 | 0.0000 |

控制触发词数后同样无残余预测力（实验 5【C】）：

| 分层 | n | 成功/失败 | AUC | p |
|---|---|---|---|---|
| n_seed=1 | 102 | 23/79 | 0.5908 | 0.186 |
| n_seed=2 | 11 | 3/8 | 0.2708 | 0.302 |

**裁决：partially，且实质是「不成立」。** 低 Ω 只在「Ω 是否等于 0」这一位上预测失败，而这一位是定理（§4.3），不是机制发现。在 Ω>0 内部，Ω 与级联通路成功**无稳定关系**。

### 4.3 为什么 Ω=0 ⟹ 通路必空是**定理**

```
无触发词命中
  → ont.match_by_triggers([]) 返回空（retrieval.py:124-125）
  → candidates 空 → for c in candidates 循环不执行 → agg 空
  → 本实验 semantic_fallback=False → 直接返回 chunk_ids=[]
```

实测：Ω=0 的 518 条中，通路非空的 **0** 条。这不是经验发现，是代码结构的必然。反向不成立：Ω>0 但通路仍空的 **66** 条（命中的框架其域闭包与图中任何 live 超边的域不相交）。

### 4.4 Ω 相对最朴素基线没有增益

| 预测器 | AUC(预测通路非空) | AUC(预测通路命中) |
|---|---|---|
| Ω（本设计） | 0.9540 | 0.9409 |
| **触发词命中数 n_seed（1 个整数）** | **0.9435** | **0.9324** |
| 观测完备度 completeness | 0.9501 | 0.9385 |
| 触发词密度 n_seed/len | 0.9501 | 0.9385 |
| Ω_geo（去完备度因子） | 0.9508 | 0.9371 |

```
Spearman ρ(Ω, n_seed) = +0.9949 (p≈0)          ← 几乎共线
Ω>0 ⟺ n_seed≥1 逐条一致率 = 632/632 = 100%
「Ω>0」预测「通路非空」一致率 = 0.8956
「n_seed≥1」预测「通路非空」一致率 = 0.8956     ← 完全相同
```

**Ω 在预测级联通路上携带的全部信息 = 1 bit（有/无触发词命中）。** 三分量几何平均 + 观测完备度的复杂结构，在这条任务上没有产生任何超出朴素计数的信号。

### 4.5 Ω 门控严格弱于现有判据

现有代码（`retrieval.py:150`）的判据是 `if not agg: semantic_fallback`——「通路**真的**为空」。Ω 门控是「通路**可能**为空」的代理：

```
「agg 空」与「Ω=0」的一致率 = 566/632 = 0.8956
不一致的 66 条全部是：Ω>0 但 agg 空（Ω 门控放行、现有判据会回退）
回退触发次数：现有判据 584 次；Ω 门控 518 次（少 66 次）
Ω 门控的阻断精度 = 1.000，但门控召回 = 1.000 是空洞的：
  它拦下的 518 条本来就零收益，拦不住 87 条「有激活但级联仍失败」的查询
```

→ **Ω 的「能门控」不带来任何新的工程动作。** 若只想门控级联通路，直接判 `n_seed > 0` 即可，无需 Ω。

## 5. 机制分解：级联通路失败的三通道（实验 3）

| 通道 | 定义 | n | 占比 | mean Ω | mean Ω_G |
|---|---|---|---|---|---|
| 0 成功 | 通路非空且命中金标 | 27 | 4.3% | 0.0192 | 0.0190 |
| **1 激活失败** | 无触发词命中 | **518** | **82.0%** | 0.0000 | 0.0000 |
| **2 覆盖失败** | 有触发词、框架点亮，但域闭包与图中任何超边不相交 | **66** | **10.4%** | 0.0316 | **0.0000** |
| 3 召回失败 | 通路非空但金标 chunk 未被覆盖 | 21 | 3.3% | 0.0297 | 0.0294 |

**Ω 只能看见通道 1，对通道 2 完全盲**（通道 2 的 mean Ω=0.0316 **高于**成功组的 0.0192——Ω 认为它们「激活良好」）：

```
通道 2（覆盖失败 n=66）vs 通道 3（通路非空 n=48）：
  Ω   mean 0.0316 vs 0.0238   AUC=0.4067     ← 不可分（甚至反向）
  Ω_G mean 0.0000 vs 0.0236   AUC=0.0000     ← 完全可分
  n_reach mean 0.000 vs 2.188
```

**Ω_G（读图版）**：把 Ω_E 的分量换成「点亮且**在图中有超边可落**的域数 / 种子触发词数」，其余不变（仍不读候选排序）。

```
AUC(预测通路非空)：Ω = 0.9540  →  Ω_G = 1.0000
AUC(预测通路命中)：Ω = 0.9409  →  Ω_G = 0.9828
Ω_G=0 的 584 条中，通路非空的 0 条、命中的 0 条
```

→ **Ω 缺的是图可达性信息，不是更多查询侧熵。** 把图加进来即可把「通路是否非空」预测到 1.000（因为通路本身是 (query, graph, ontology) 的确定性函数）。但读图后 Ω 就不再是纯查询侧泛函，参考设计的核心不变式（不受候选污染）也随之放弃——这是真实取舍，无法两全。

通道 3（覆盖后未命中金标）需要候选侧信号，超出「纯查询侧」设计能覆盖的范围：

```
通道 3 内部：成功 n=27 vs 召回失败 n=21
  Ω   mean 0.0192 vs 0.0297  AUC=0.5018  p=0.992   ← 完全不可分
  Ω_G mean 0.0190 vs 0.0294  AUC=0.5035  p=0.975   ← 完全不可分
  级联召回 mean 0.9753 vs 0.0000                     ← 差距全在候选侧
```

### 5.1 改写型里 Ω>0 靠的是什么触发词

Ω>0 的 114 条改写查询共命中 127 次触发词（去重 78 个），命中词的「运气成分」极大：

| 触发词 | 命中条数 | 该词命中后通路成功率 |
|---|---|---|
| 眼睛 | 7 | **0.000** |
| 充满 | 6 | 0.333 |
| 黑夜 | 5 | **0.000** |
| 方向 | 5 | **0.000** |
| 传递 | 4 | **0.750** |
| 流逝 | 4 | 0.250 |
| 歌声 | 4 | **0.000** |
| 构建 | 3 | **1.000** |

同一个 Ω>0，背后可能是「构建」（通路必成）也可能是「眼睛」（通路必败）。这解释了为什么 Ω>0 内部无区分力：**Ω 度量的是「有没有撞上触发词」，而不是「撞上的触发词是否指向查询所需的结构」**。

## 6. 基底结构诊断：三处「参考设计 ↔ 本项目基底」错配（实验 6）

参考设计的三个分量预设了它的基底里「扩展」「流量」是**拓扑上可能**的。本项目的隐喻基底不是同构的。

### 6.1 Ω_N 是死分量

```
生产本体 758 个级联中，成员共享同一 target_domain 的：752 个 = 99.2%
成员数=1 的级联：412/758 = 54.4%
单框架出发、级联闭包不带来新目标域的框架：2196/2209 = 99.4%
根因：ontology_clean 的 LLM 级联按 target_domain 分组生成（LLM_TARGET::{t}）
      → 成员必然共享目标域 → 「涌现目标域」恒为空集
对照·内置种子级联（13 个，人工构造）：6 个是多目标域
Ω_N>0 占比：改写型 9/632 = 1.4%；重叠型 33/632 = 5.2%
```

把 Ω_N 置为 1（即从几何平均里移除该分量）后，Ω 平均变化 **+0.1207**（n=114，中位 +0.1099）。**Ω_N 把 Ω 整体压低约 3–5 倍，但不提供任何查询间区分度。** 它只是给所有 Ω>0 的查询乘了一个近似常数因子。

### 6.2 Ω 对触发词数**非单调**

| 查询 | n_seed | len | Ω_E | Ω_F | comp | Ω_geo | Ω |
|---|---|---|---|---|---|---|---|
| 泥潭 | 1 | 2 | 1.000 | 0.500 | 1.000 | 0.794 | **0.794** |
| 泥潭，沼泽 | 2 | 5 | 0.500 | 0.500 | 0.800 | 0.630 | 0.504 |
| 泥潭，沼泽，陷进 | 3 | 8 | 0.333 | 0.500 | 0.750 | 0.481 | 0.361 |
| 泥潭，沼泽，陷进，深坑 | 4 | 11 | 0.250 | 0.500 | 0.727 | 0.397 | **0.289** |

两条反向机制：

1. **Ω_E 的分母是「种子触发词数」** —— 多个触发词坍缩到同一框架时分母涨、分子不涨（`泥潭，沼泽` 的 Ω_E=0.5 而非 1.0）。触发词间常有同义冗余，这不是「激活不充分」。
2. **完备度 = 覆盖字符/查询长度** —— 查询越长惩罚越重。

因此 Ω 与 n_seed 在全样本上的 ρ=0.9949 **是 0 块（518 条 Ω=0）主导的假象**；在 Ω>0 区间内两者关系是非单调的。这一点已固化为测试 `test_omega_is_not_monotone_in_trigger_count`。

### 6.3 Ω 与「触发词有无」1 bit 等价

见 §4.4。三重一致率（Ω>0 / n_seed≥1 / 通路非空）完全相同 = 0.8956。

## 7. 非构造对照：低 Ω 是基准产物还是普遍现象？（实验 4）

实验 2【C】发现红线过滤（生成改写时程序化禁止出现触发词/域词）**不是**低 Ω 的主因：

```
被红线剔除的 226 条：Ω=0 占比 77.0%，mean=0.0046
保留进评测的 632 条：Ω=0 占比 82.0%，mean=0.0051
AUC(剔除组 Ω > 保留组 Ω) = 0.5255   ← 几乎无分离
```

原因：红线只禁**该条金标边自己的**触发词，而本体有 774 个触发词——改写句即使不含本边触发词，仍可能撞上其它边的触发词。

四个**未经任何基准构造干预**的查询族：

| 族 | n | mean len | Ω=0 | collapsed | sparse | dense | mean Ω |
|---|---|---|---|---|---|---|---|
| N1 CCL2018 原句（真实标注句） | 1100 | 19.1 | 62.3% | **62.3%** | 37.7% | 0.0% | 0.0096 |
| N2 连贯文档 chunk 全文 | 1050 | 416.3 | 21.8% | **21.8%** | 78.2% | 0.0% | 0.0031 |
| N3a 文档句·含触发词 | 847 | 26.6 | 0.0% | **0.0%** | 100.0% | 0.0% | 0.0145 |
| N3b 文档句·不含触发词 | 3000 | 22.9 | 100.0% | **100.0%** | 0.0% | 0.0% | 0.0000 |
| *C1 改写型（对照）* | 632 | 13.5 | 82.0% | 82.0% | 17.9% | 0.2% | 0.0051 |
| *C2 重叠型（对照）* | 632 | 2.5 | 58.4% | 58.4% | 36.9% | 4.7% | 0.0745 |

**三个关键观察**：

1. **CCL2018 原句同样 62.3% collapsed** —— 真实标注的中文隐喻句，六成以上查不到任何本体触发词。
2. **N2/N3a 的 collapsed 率低，但代价是查询变长** —— 完备度因子把长查询系统性压低（N2 均 416 字 → comp=0.0114），所以 N2 的 mean Ω（0.0031）反而**低于**改写型（0.0051），尽管它的 collapsed 率只有 21.8%。**Ω 的两个因子互相打架**：长查询不易 collapsed（触发词多）但完备度极低。
3. **dense 几乎不存在** —— 除重叠型（4.7%）外，所有自然查询族的 dense 率都是 0.0%。阈值 0.5 在本基底上几乎不可达。

→ **低 Ω 反映的是「774 词种子触发词表相对中文自然语言的长尾覆盖不足」这一本体层事实**，不是「查询不连贯」。它在本体层真实、可复现、跨语料一致——但它的**机制**在本体覆盖，不在查询语义。

### 7.1 regime × 级联通路成功（两个构造族）

| 族 | regime | n | 通路成功 | 成功率 | mean Ω |
|---|---|---|---|---|---|
| 改写型 | collapsed | 518 | 0 | **0.0000** | 0.0000 |
| 改写型 | sparse | 113 | 27 | 0.2389 | 0.0242 |
| 改写型 | dense | 1 | 0 | 0.0000 | 0.5000 |
| 重叠型 | collapsed | 369 | 0 | **0.0000** | 0.0000 |
| 重叠型 | sparse | 233 | 191 | **0.8197** | 0.0890 |
| 重叠型 | dense | 30 | 25 | **0.8333** | 0.8778 |

**两个族里 collapsed 的通路成功率都恰好是 0.0000**（合计 887 条）——这是 §4.3 那条定理的直接体现，不是经验规律。真正有信息的是 sparse/dense 之间的差异：

- 改写型 sparse 0.2389 vs 重叠型 sparse 0.8197 —— 同为 sparse，差 3.4 倍。**regime 标签不足以刻画通路前景**，这正是 §4.2「Ω>0 内部无区分力」的另一种呈现。
- 重叠型 dense 0.8333（n=30）比 sparse 0.8197 只高 1.4pp —— 即便在 regime 层面，Ω 从 sparse 升到 dense 也几乎没有额外信息。
- 改写型的 dense 只有 1 条，无统计意义。

重叠型全量查询池（n=861，含未进入改写池的查询）：collapsed 521（60.5%）/ sparse 303（35.2%）/ dense 37（4.3%）。

## 8. 自批判与循环性分析（必须读的一节）

### 8.1 分离是不是同义反复？

**部分是。** 需要区分两个断言：

- **弱断言（成立）**：「Ω 在改写型上系统性低于重叠型」——真实、显著、CI 不含 0.5，且补长后仍在。
- **强断言（不成立）**：「Ω 度量了查询激活隐喻结构的连贯程度」——不成立。因为 Ω>0 ⟺ 命中触发词，而「命中触发词」只是「查询字面复用本体词表」，与「查询的隐喻语义是否连贯」是两件事。反证：`构建` 命中后通路成功 3/3，`眼睛` 命中后 0/7，而两者 Ω 可能相同。

### 8.2 Ω=0 ⟹ 通路失败是定理，不是发现

§4.3 已证。**如果研究报告「低 Ω 预测级联失败」而不说这一层，就是在把恒真式包装成发现。** 本报告显式区分。

### 8.3 分离会不会被「0 块」完全解释？

**是。** 82.0% 的改写型 Ω 恰好 = 0，58.4% 的重叠型 Ω = 0。全样本的 AUC=0.349 与 δ=−0.301 主要由这两块的相对大小决定。去掉任一侧的 0 后（两侧 Ω>0，n=46）：

```
改写型 mean=0.0226 median=0.0122
重叠型 mean=0.2098 median=0.1000
AUC=0.0312  δ=−0.9376  MWU p=6.4e-15     ← 分离反而**更强**
```

即：**在都能激活结构的查询里，改写型的激活强度只有重叠型的约 1/9**（mean 0.0226 vs 0.2098，δ=−0.94）。这是本实验**最强、也最值得报告的正面发现**——它不依赖 0 块，且效应量很大。但它同时也把 Ω 的语义钉死了：Ω 度量的是**字面词表命中强度**，不是语义连贯度。

### 8.4 与现有信号的独立性

Ω 与候选侧信号（`metaphor_coherence`、LLM 逐链判定、排序器 7 维特征）**结构性独立**（§1.2），这一点确实填补了「没有查询侧标量」的缺口。但独立性不等于有用性：本实验证明它独立于候选池，同时证明它**不携带超出触发词计数的信息**。独立 + 无信息 = 一个干净的、可审计的、但**当前不可用于门控或排序**的观测量。

### 8.5 我可能错在哪里

1. **阈值 0.5 是任意的。** sparse/dense 分界若改成 0.2，N3a（文档句·含触发词）的 dense 率从 0.0% 升到 0.1%；改成 0.1 则升到 2.7%。**结论方向不变**（自然查询族基本无 dense），但具体百分比是阈值产物。已实测：

   | sparse_max | N3a collapsed | N3a sparse | N3a dense |
   |---|---|---|---|
   | 0.5 | 0.0% | 100.0% | 0.0% |
   | 0.3 | 0.0% | 100.0% | 0.0% |
   | 0.2 | 0.0% | 99.9% | 0.1% |
   | 0.1 | 0.0% | 97.3% | 2.7% |

   模块已暴露 `sparse_max` 参数，但本报告只报 0.5 的结果。
2. **Ω_G 的对比不是公平的。** Ω_G 读图、Ω 不读图，比较两者是说明「Ω 缺哪层信息」，不是说 Ω 设计差。
3. **重叠型查询是构造物。** 「触发词拼接」不是真实用户查询，它把 Ω 的上界人为抬高（`泥潭` 单词查询 Ω=0.794，因为完备度=1.0）。真实用户不会这么问。因此「改写型 vs 重叠型」的对比有基准构造成分，实验 4 的自然族对照是对它的必要补充。
4. **本实验只在中文 + 774 触发词种子词表上做。** 若换成一个触发词覆盖良好的本体（例如把 774 扩到 5000），Ω 的分布会整体上移，`Ω=0` 块缩小，结论可能变化。这是本报告最重要的外推边界。
5. **单文档、无跨文档检索。** Ω 只在本伪文档范围内测（与 `cross_domain_retrieve` 口径一致）。

### 8.6 参考设计的声称边界（我们严格遵守）

参考设计明确只声称 Ω「**能测**」与「**能门控**」，**不声称**提升下游指标。本实验的结论与之相容：

- 「能测」✅ —— Ω 可算、可审计、可解释（`QueryObservability` 保留了命中的触发词/点亮的框架/涌现域/流量权重，出问题时能回答「为什么低」）。
- 「能门控」⚠️ —— 技术上能门控，但门控能力**严格弱于现有 `if not agg` 判据**（§4.5），因此在本项目里不带来新动作。
- 「提升下游指标」—— 未声称，本实验也未测（Ω 未接入任何检索路径，已上报数字全部未变）。

## 9. 如果要把 Ω 做对：具体修法

| 问题 | 修法 |
|---|---|
| Ω_N 死分量 | 要么修基底（让生产级联允许成员跨目标域——种子本体 13 个里 6 个做到了），要么把 Ω_N 从几何平均移除，或改定义为「点亮的**级联**数 / 种子数」 |
| Ω 对词数非单调 | Ω_E 的分母不该是「种子触发词数」（触发词有同义冗余），应是「点亮的结构数上限」；或改为「点亮框架数 / 该查询可达的框架数上限」 |
| 完备度因子与 collapsed 率互相打架 | 改为阈值化形式（如 `min(1, 覆盖字符/2)`），去掉长度线性惩罚 |
| 只有 1 bit 信息 | 若目的是**门控**：直接判 `n_seed > 0`，不必用 Ω。若目的是**度量激活结构**：必须读图（Ω_G 把 AUC 0.954→1.000），但须放弃「纯查询侧」不变式 |
| 通道 3（覆盖后未命中）不可判 | 需要候选侧信号，超出纯查询侧设计范围——这是设计边界，不是实现缺陷 |
