## 0. TL;DR（诚实结论）

1. **事实 1、2、4 复核成立；事实 3 只在渐近意义下成立。**
   `S` 行和精确为 1.0、`ρ(S) = 1.0`；无源项迭代 `X ← M X` 在 500 层后
   同分量平均余弦 = 1.000000（确认坍缩）。**但 H4 实际工作在 `layers=2`，
   此时远未坍缩**（同分量余弦仅 0.383，跨分量 0.072）。
   所以「H4 的 0.950 是算子退化造成的」这一说法 **REFUTED**。

2. **加源项没有打破 flat-vs-HGNN 平局，也没有改变「信号来自 L1 n 元共现、
   而非层级」的结论。** 在 α ∈ {0.1…1.0} × ε ∈ {0, 0.1, 0.2} 的 18 个
   配置下，`acc_hgnn` 与 `acc_flat` 始终相差 ≤ 0.05（n=20，分辨率 0.05），
   高功效 AUC 版差值全部落在 **|ΔAUC| ≤ 0.005**（95% CI 跨 0）。
   结论 **UNDETERMINED→REFUTED 方向**：源项不是平局的原因。

3. **源项确实提升了「分量内」判别力**（同分量 AUC 0.708 vs α=1 的 0.708…）
   —— 更准确的表述：源项让**深层迭代**（layers ≥ 50）不再坍缩，
   而 `layers=2` 下两者几乎无差别。见 §5。

4. **新负面结果：原 H4 的 `raw = 0.150`（低于随机）是口径产物，不是
   「反向判别」。** 默认哈希编码器下抽象域标签（「旅程」「停滞」）几乎无
   共享 n-gram，**80% 的配对余弦精确并列（=0）**，而配对准确率把并列计为
   错误。raw 的真实状态是「**无信息**」，不是「有害」。

5. **新负面结果：n=20 的 H4 配对准确率统计功效不足**，其「结论字符串」
   会随 α 抖动而翻转（α=0.5 时打印「依赖跨层传播 ✅」），而同期 AUC
   完全稳定。**建议把 H4 的主指标换成全量负样本 AUC。**

## 5. `metaphor_coherence` 是否变得更有判别力？

**测量设计**（区分「同分量指示器」与「真判别器」的两把尺子）：

- **A（原 H4 口径）**：负样本跨分量 → 同分量指示器也能拿高分，**不可区分**。
- **B（关键测试）**：负样本限制在 **src 的同分量内**。
  纯同分量指示器在该子集上分数恒定 → 准确率必然 **0.5**、AUC 必然 **0.5000**。
- **C**：同分量内 `coherence` 与**超图跳数**的 Spearman 秩相关（分量内中心化）。
  纯指示器恒为 0；越负说明越能分辨「近 vs 远」。
- **D**：分量内 coherence 的离散度。纯指示器 → 0。

### B/C/D 结果（`layers=2`）

| α | ε | A: 跨分量负 acc | B: **同分量负 acc** | B 并列数 | C: ρ(跳数, coh) | D: 分量内 std |
|---|---|---|---|---|---|---|
| 1.00 | 0.00 | 1.000 | 0.555 | 3 | −0.7759 | 0.26989 |
| 0.90 | 0.00 | 1.000 | 0.593 | 4 | −0.7692 | 0.22591 |
| 0.70 | 0.00 | 0.929 | 0.555 | 3 | −0.7483 | 0.17407 |
| 0.50 | 0.00 | 0.857 | **0.742** | 0 | −0.7386 | 0.15611 |
| 0.30 | 0.00 | 0.857 | 0.632 | 1 | −0.7290 | 0.15094 |
| 0.10 | 0.00 | 0.857 | 0.555 | 3 | −0.7307 | 0.14952 |
| 0.50 | 0.10 | 0.857 | 0.632 | 2 | −0.7354 | 0.15468 |
| 0.50 | 0.20 | 0.857 | 0.555 | 1 | −0.7314 | 0.15346 |

**在 `layers=2`，α=1.0 的 B 列已经是 0.555（> 0.5），C 列 ρ = −0.776
（强负相关），D = 0.270（非零）—— 即 `layers=2` 下的 coherence 本来就不是
同分量指示器。** 源项并没有把「指示器」升级成「判别器」；它只是让
**深层迭代**不再坍缩。α=0.5 时 B 列升到 0.742、D 降到 0.156，
是「分数整体被压缩到更小尺度」的副产物，判别力（AUC）反而略降。

| α | layers | **分量内 AUC** | 跨分量 AUC | #正 | #负(同分量) |
|---|---|---|---|---|---|

  **在 H4 的工作点上，源项让判别力略微变差，不是变好。**

## 6. 新负面结果

### 6.1 `raw = 0.150` 是「并列惩罚」的口径产物，不是反向判别

`experiments/diag_raw_baseline.py` + `tie_analysis.py`：

| 指标 | 值 |
|---|---|
| cos_pos 恰为 0 的比例 | **0.850** |
| cos_neg 恰为 0 的比例 | **0.950** |
| **配对并列率（cos_pos == cos_neg）** | **0.800** |
| 配对准确率 P(pos > neg) | 0.150 |

默认哈希编码器对抽象域标签（「旅程」「停滞」「阵地」）产生的向量几乎无
共享 n-gram → 余弦**精确为 0**。20 个配对里 16 个是**精确并列**；
`acc = P(pos > neg)` 把并列计为错误，于是 `acc = 3/20 = 0.150`。

**正确解读**：raw 基线在默认编码器下 **AUC = 0.5500 ≈ 无信息**，
而不是「反向判别（< 0.5）」。原报告把它当作「结构信号的必要性证据」时
需注意这一点：它证明的是 raw **不够用**，不是 raw **有害**。
（在真实句向量下这个数字会变，但那需要 API 调用，超出本次 $0 约束。）

### 6.2 n=20 的 H4 配对准确率统计功效不足，结论字符串会翻转

`python -m metaphor_graph.evaluate_hgnn --alpha 0.5` 打印：

```
→ 简单对照均无法复现：图结构校验信号依赖超图（跨层）传播 ✅
```

而 `--alpha 1.0`（原始口径）打印：

```
→ flat(仅 L1 超边)即可复现：信号来自喻底 n 元共现，跨层层级非必要（诚实负面）
```

**同一份数据、同一个指标、只是 α 从 1.0 变到 0.5，结论字符串就翻转了**
（`acc_flat` 0.950→0.900，一个样本对之差）。而同期高功效 AUC 从
0.9409→0.9092，**`flat` 与 `hgnn` 的相对关系没变**。

→ **原 H4 的判定阈值（`flat >= hgnn − 0.02`）在 n=20、分辨率 0.05 下
不可靠。建议改用全量负样本 AUC（`experiments/auc_h4.py`）。**

### 6.3 源项不改变 P4-A 检索增益结论

`measure_p4a` 在 α ∈ {1.0, 0.5, 0.1} 下 MRR@10 = 0.896、Hits@3 = 0.875、
Hits@10 = 1.000 **完全相同**（HGNN 相对原始嵌入 −0.104）。
逐查询排序确有变化（5/8 查询的排序在 α<1 时改变），但聚合指标在 n=8 下
分辨不出来。**§4.5「跨层传播改善检索」的负面结论不受源项影响。**

### 6.4 一个分析陷阱（供后续复用）

`_common.py` 里 `coherence_lookup` 必须覆盖**全部节点**（实体+框架+级联）。
我第一版只覆盖实体，涉及框架/级联节点的节点对静默取 0.0，
把「分量内离散度」污染成虚高值。同理 Spearman 必须**分量内中心化**，
否则会把「分量间差异」误读成「分量内梯度」（修正后 ρ 从 −0.85 变为 −0.78，
量级不变但语义正确）。

## 7. 结论判定

| 命题 | 判定 |
|---|---|
| `S` 行和恰为 1、`ρ(S)=1` | **SUPPORTED**（精确，1e-12 内） |
| 无源项迭代坍缩到分量平稳分布（k→∞） | **SUPPORTED**（500 层同分量余弦 1.000000） |
| `metaphor_coherence` 退化为同分量指示器 | **SUPPORTED，但仅渐近**；`layers=2` 时分量内 AUC=0.7075，远未退化 |
| 「**H4 报告的 flat/HGNN 平局是算子退化造成的**」 | **REFUTED** —— 平局在 α=0.1…1.0、ε=0…0.2 的 18 个配置下全部保持（\|ΔAUC\| ≤ 0.005）；且 `layers=2` 无退化；且「完美同分量指示器」在 H4 的配对样本上准确率上限只有 **16/20 = 0.8000**（实测：仅 2/13、2/7 负样本同分量），**低于实测的 0.950**，故退化无论如何解释不了 0.950 |
| 源项「改变」了 H4 的「信号来自 L1 n 元共现、非层级」结论 | **REFUTED** —— 结论不变，且高功效 AUC 下更明确 |
| 源项能防止深层迭代坍缩 | **SUPPORTED** —— α=0.5、500 层 AUC 0.6803 vs α=1.0 的 0.5413 |
| 源项在 H4 工作点（`layers=2`）提升判别力 | **REFUTED** —— AUC 0.6807 (α=0.5) < 0.7075 (α=1.0) |
| `raw = 0.150` 反映「原始嵌入反向判别」 | **REFUTED** —— 80% 精确并列；AUC=0.550 即「无信息」 |

### 对论文/报告的建议

1. **保留**「信号来自 L1 喻底 n 元共现，跨层层级非必要」的诚实负面结论 —— 
   本次实验在更严格的检验（18 配置 × 高功效 AUC）下**再次确认**它。
2. **不要**把「算子退化」写成 H4 平局的解释 —— 退化是渐近的，
   H4 工作在 `layers=2`，两者不在同一 regime。
3. **把 H4 的主指标换成全量负样本 AUC**（`experiments/auc_h4.py`），
   并把 n=20 的配对准确率降级为辅助。当前 0.02 阈值在 n=20 下不可靠。
4. **修正 raw 基线的表述**：从「0.150 低于随机」改为
   「AUC 0.550，默认哈希编码器下无判别信息（80% 配对精确并列）」。
5. 若论文需要引用源项/阻尼算子（RiverMemo 式），可以报告：ε>0 使
   `Σ_j P_ij = 1−ε/2 < 1` 严格成立、`ρ ≤ 1−ε/2`，但**代价是质量不守恒**
   （ε=0.5、50 层范数下溢为 0），故只在配合源项时可用。
