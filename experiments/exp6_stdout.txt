【S1】级联闭包 = 回声：Ω_N 在生产本体上几乎恒为 0
--------------------------------------------------------------------------------------------
  级联成员目标域唯一（闭包不带来新域）的级联：752/758 = 99.2%
  成员数=1 的级联：412/758 = 54.4%
  单框架出发、级联闭包不带来新目标域的框架：2196/2209 = 99.4%
  根因：ontology_clean 的 LLM 级联按 target_domain 分组（`LLM_TARGET::{t}`）→ 成员必然共享目标域
  对照·内置种子级联（13 个，人工构造）：多目标域的有 6 个
  改写型 Ω_N>0 占比 = 9/632 = 1.4%  mean=0.0142
  重叠型 Ω_N>0 占比 = 33/632 = 5.2%  mean=0.0514
  把 Ω_N 置为 1（即从几何平均中移除该分量）后，Ω 平均变化 = +0.1207（n=114，中位 +0.1099）
  → Ω_N 在本基底上是**死分量**：它把 Ω 整体压低约 3–5 倍，但不提供任何查询间区分度

  两条反向机制：
    (i)  Ω_E = 点亮框架数 / 种子触发词数 —— 多个触发词坍缩到同一框架时分母涨、分子不涨 → Ω_E 下降（"泥潭，沼泽" 的 Ω_E=0.5 而非 1.0）
    (ii) 完备度 = 覆盖字符 / 查询长度 —— 查询越长惩罚越重（4 词拼接 11 字 → comp=0.727）
  → 在真实数据上 Ω 与 n_seed 仍秩相关 0.995，是因为 0 块（无命中）主导；在 Ω>0 区间内 Ω 与 n_seed 的关系是**非单调**的

    n_seed=2: n= 11 mean Ω=0.0999 median=0.0308

【S3】信息量核算：Ω 在预测级联通路上 = 1 bit
--------------------------------------------------------------------------------------------
  Ω>0 与 n_seed≥1 的逐条一致率 = 632/632 = 1.0000
  Ω>0 与「通路非空」的一致率 = 0.8956
  n_seed≥1 与「通路非空」的一致率 = 0.8956
  → 三者一致：Ω 在「通路是否非空」上的信息 = 触发词有无 = 1 bit

  额外信息量的唯一来源是 Ω 的连续部分，实测：
    Ω>0 内 Ω × 通路命中：点二列 r=-0.0848 p=3.696e-01；Spearman ρ=0.1316 p=1.627e-01
    （点二列与 Spearman 符号相反 —— 说明 Ω>0 区间内没有稳定方向，只是噪声）

--------------------------------------------------------------------------------------------
【结论】三处设计-基底错配与具体修法
--------------------------------------------------------------------------------------------
  S1 Ω_N 死分量 -> 若基底级联要承载「涌现」，级联必须允许成员跨目标域
     （种子本体做到了：13 个里有 6 个跨域；生产本体 758 个里只有 6 个）。
     在此之前，Ω_N 应从几何平均里移除，或改为「点亮的级联数 / 种子数」。
  S2 非单调 -> Ω_E 的分母不该是「种子触发词数」（触发词可以同义冗余），
     而应是「点亮的结构数上限」；完备度因子应改为触发词覆盖率的
     阈值化形式（例如 min(1, 覆盖字符/2)），否则长查询被系统性压低。
  S3 1 bit -> 若 Ω 的目的是门控级联通路，直接判 n_seed > 0 即可，
     不需要 Ω；若目的是度量激活了多少结构，必须让 Ω 读图
     （实验 3 的 Ω_G：AUC 0.954 -> 1.000）。但读图后 Ω 就不再是纯查询侧
     泛函，参考设计的核心不变式（不受候选污染）也随之放弃 —— 这是真实的
     取舍，不是可以两全的工程细节。
