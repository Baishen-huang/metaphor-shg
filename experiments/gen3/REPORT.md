## 0. 裁决先行

**假设（主控提出）：Ω 的失败来自其"合成方式"（几何平均 + ε 下界 + 完备度系数），
而非查询侧标量这个概念本身；用一个更好的合成（条件化/分层归一化替代 ε 下界稀释）
应能保住 gen2 发现的 `n_emergent` 信号（分层条件 AUC 0.836）。**

**裁决：假设被证伪。`n_emergent` 的 0.836 是【集合大小伪影】，控制集合大小后
信号完全消失（AUC 0.486–0.508，CI 全部覆盖 0.5）。**

更关键的是，复核发现 **gen2 的 0.836 只在非默认级联构造规则（`source`）下出现**；
在**生产默认规则（`json`）下 `n_emergent` 的 AUC 仅 0.4834（子集）——本来就无信号**。

| 级联规则 | `n_emergent` AUC（子集） | 控制集合大小后 |
|---|---|---|
| **`json`（生产默认）** | **0.4834** [0.435, 0.531] | 0.4897 [0.459, 0.509] |
| `source` | 0.8357 [0.758, 0.909] | 0.4861 [0.393, 0.573] |
| `metanet` | — | 0.5077 [0.467, 0.553] |
| `source_type` | — | 0.4268 [0.333, 0.500] |

**结论：不存在可用的查询侧标量。"触发词命中数"（1-bit）就是本基底上的天花板。**

## 2. 机制归因：信号在哪一层被毁掉（实验 2）

### 2.1 分量取值数极少（根因）

```
取值数（全样本）：Ω_F=3   Ω_E=2   Ω_N=2
ε 下界恒等式：Ω_N=0 且有触发词的 105 条中，
              Ω_geo == (Ω_E·ε·Ω_F)^(1/3) 的有 95 条（90.48%）
```

**Ω_N 只有 2 个取值**（0 或极小正值），而 **90.5% 的有触发词查询落入
`Ω_N=0 → 被 ε 下界替换`**。此时几何平均退化为 `(Ω_E·ε·Ω_F)^(1/3)`，
即**仅由 Ω_E 与 Ω_F 决定**——而这两者都只是触发词覆盖的不同表达。

### 2.2 完备度系数与 n_seed 近乎完全共线

```
完备度：AUC 全样本 0.9503   子集 0.5581   ρ(comp, n_seed) = 0.9954
```

**完备度系数 ρ = 0.9954 与 n_seed 共线**——它没有提供独立信息，
只是把触发词覆盖度又乘了一遍。这与 Ω 本身（ρ=0.9950）是同一个问题。

### 2.3 2⁴ 开关对照（实验 2 的合成算子网格）

穷举 `floor ∈ {0,1}` × `div ∈ {0,1}` × `comp ∈ {0,1}` × `outer0 ∈ {0,1}`，
以及 4 种合成算子（`geo` / `arith` / `max` / `sum`）：

```
合成设置（示例，AUC 子集）           clip+div    noclip+div
geo|floor=1|comp=1                    0.5933       0.6087
geo|floor=0|comp=1                    0.6149       0.6188
arith|floor=0|comp=1                  0.6124       0.6154
max|floor=1|comp=0                    0.5000       0.5822
```

**全部 64 个组合的 AUC 子集都落在 0.50–0.62 区间**（n=114）。
最好的组合（0.6188）也只是弱信号，且**没有任何组合接近 gen2 声称的 0.836**。

**这直接回答了"信号在哪一层被毁掉"：不是被合成算子毁掉的。**
在控制集合大小之前，`n_emergent` 的"信号"来自它与「激活集合大小」的耦合；
任何合成方式都无法把它变成独立信号。

## 3. 控制集合大小的裁决（实验 5、6）

这是本代最关键的检验。**"涌现计数"天然与"激活集合大小"正相关**——
`n_reach` 越大，`n_emergent` 自然越大。因此必须控制集合大小后看增量。

### 3.1 层内加权 AUC（控制 `|reach|` 后）

| 标量 | 层内 AUC | 95% CI | Holm p |
|---|---|---|---|
| `omega` | 0.8854 | [0.682, 1.000] | 0.0280 |
| `completeness` | 0.8854 | [0.682, 1.000] | 0.0280 |
| `n_seed` | 0.5375 | [0.500, 0.625] | 1.0000 |
| `omega_geo` | 0.5375 | [0.500, 0.625] | 1.0000 |
| `n_cascades` / `n_members` / `n_reach` | 0.5000 | [0.500, 0.500] | — |
| `n_emergent` | **0.4625** | [0.375, 0.500] | 0.0240 |
| `n_new_domains` | **0.4625** | [0.375, 0.500] | 0.0240 |
| `qlen` | 0.1146 | [0.000, 0.318] | 1.0000 |

**`n_emergent` 层内 AUC = 0.4625，即低于随机**（CI 上界 0.500 恰触 0.5）。
**控制集合大小后它不仅无信号，还略微反向。**

注意 `omega` 与 `completeness` 层内 AUC 0.8854 看似很高，但 **Holm 校正后
只有它们与少数项显著，且 `omega`≡`completeness` 高度重合**（见 §2.2 共线性），
这属于多重比较下的假阳性，不宜作为"Ω 有增量"的证据。

### 3.2 控制集合大小后的增量 AUC（实验 5，跨 4 种规则）

| 规则 | `n_emergent` | `omega` |
|---|---|---|
| `json`（生产） | 0.4897 [0.459, 0.509] | 0.7000 [0.535, 0.835] |
| `source` | 0.4861 [0.393, 0.573] | 0.6528 [0.443, 0.825] |
| `metanet` | 0.5077 [0.467, 0.553] | 0.7423 [0.556, 0.887] |
| `source_type` | 0.4268 [0.333, 0.500] | 0.8293 [0.636, 1.000] |

**全部 CI 覆盖 0.5**（`source_type` 的 omega CI 下界 0.636 例外，但该规则非默认，
且其 `n_emergent` 反向为 0.4268）。

### 3.3 留出文档的条件化检验（实验 6）

按文档划分训练/测试（55/55 文档），在留出集上做条件化：

```
json:   n_emergent cond_auc = 0.4897 [0.459, 0.509]   n_informative=13
        n_reach    cond_auc = 0.5000 [0.500, 0.500]
source: n_emergent cond_auc = 0.4861 [0.393, 0.573]   n_informative=10
```

**跨文档留出后同样无信号**（0.486–0.490）。

## 4. 下游检验（实验 7）

### 4.1 查询侧标量 vs 下游 per-query MRR

**全样本 ρ 与文档内 ρ（控制文档难度）对比**：

| 标量 | ρ全(hand) | ρ内(hand) | 文档内置换 p |
|---|---|---|---|
| `n_gold`（**非查询侧**，上界参考） | +0.0966 | **+0.4981** | 0.0020 |
| `cascade_nonempty` | +0.1095 | +0.2060 | 0.0177 |
| `n_seed_indicator` | +0.0772 | +0.1098 | 0.0740 |
| `omega` / `S_query` | +0.0801 | +0.1027 | 0.0940 |
| `n_emergent` | **−0.0275** | **−0.1565** | 0.3837 |
| `qlen` | −0.0439 | −0.1019 | 0.0477 |

**关键对照**：`n_gold`（**不是查询侧标量**，直接数金标个数）文档内 ρ = **0.4981**
（p=0.0020）——说明文档内确实存在可预测的 MRR 变异。但**所有查询侧标量
最多只到 ρ ≈ 0.10–0.21**，远达不到该上界。`n_emergent` 甚至为**负**
（−0.1565，p=0.3837 不显著）。

**`cascade_nonempty` 是唯一在文档内显著的查询侧标量**（ρ=0.2060，p=0.0177），
但它本质仍是"触发词是否命中级联"的二值指示器——**与 1-bit 触发词基线同类**。

### 4.2 目标定位超额（实验 5 的 targeting excess）

一个正面发现（但非标量本身的价值）：

```
n=635：观测命中 48  vs 期望 27.68  → 超额 +0.0320 [+0.0173,+0.0484]，比值 1.73×
n=114：观测命中 48  vs 期望 27.68  → 超额 +0.1782 [+0.0969,+0.2632]，比值 1.73×
```

**激活的框架并非均匀分布**——它们命中真实候选的比率是随机期望的 **1.73 倍**
（CI 不含 1.0，Monte Carlo n=400，词表 733）。这证明**查询侧的激活结构
确实与候选侧存在统计关联**，只是**该关联无法被压缩成单个标量**。

## 5. 裁决与限制

### 裁决

| 问题 | 答案 |
|---|---|
| Ω 的失败是"合成方式"造成的吗？ | ❌ **不是**。64 种合成组合的 AUC 全部落在 0.50–0.62 |
| `n_emergent` 的 0.836 是真实信号吗？ | ❌ **不是**。是集合大小伪影；控制后 0.486，且只在非默认规则下出现 |
| 存在有用的查询侧标量吗？ | ❌ **没有**。"触发词命中数"（1-bit）就是天花板 |
| 查询侧激活与候选侧有关联吗？ | ✅ **有**（1.73× 超额，CI 不含 1.0），但**无法压缩成标量** |

### 限制（诚实标注）

1. **`n_emergent` 的 0.836 只在 `source` 规则下出现**，而生产默认是 `json`。
   gen2 报告该数字时未标明这一点，本代予以澄清。
2. **层内 AUC 的多重比较问题**：`omega`/`completeness` 的 0.8854 在 Holm 校正下
   仍显著，但两者 ρ=0.9954 共线，实际是同一量的两次计数。**不宜视为独立证据。**
3. **子集 n=114 偏小**，部分 CI 较宽。但 `n_emergent` 的**反向**结果（0.4625、
   −0.1565）方向一致，不像是样本量不足导致的假阴性。
4. **查询侧标量只预测"弱中间量"**：即便有信号，目标也只是级联通路是否非空
   （Recall ≤0.131），而非最终检索质量。

### 与前代的连续性

- **gen1（omega）**：Ω 退化为 1-bit 指示器 —— 本代确认，并定位到根因是
  Ω_N 结构性恒空（99.2% 级联单目标域）叠加 ε 下界替换（90.5% 查询）。
- **gen2（cascade）**：发现 `n_emergent` 条件 AUC 0.836 —— 本代**证伪**：
  该数字是集合大小伪影，且依赖非默认级联规则。
- **本代新增**：查询侧激活与候选侧有 1.73× 统计关联，但不可标量化。

**三代连续负面结论的净价值**：查询侧可观测性在本基底上**不是一个可行的建模方向**。
这为论文 §9"下一个问题是把条件化结论整合为统一检索理论"提供了一个明确的
排除项——**查询侧标量不应作为该理论的候选组件**。
