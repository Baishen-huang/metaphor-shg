gen3 实验三：指标批判 —— 金标构造混杂量化
====================================================================================================

【缺陷 1】候选 chunk 池大小（Hits@10 恒为 1 的原因）
  池大小：min=2 median=7 max=10 mean=7.03
  池 ≤ 10 的查询占比 = 100.0%  → Hits@10 在 100% 的查询上平凡为 1.000（实测确实全部 1.0000）
  池 ≤ 3 的查询占比 = 2.2%  → 一个随机排序器的期望 MRR 就有 0.262
  随机排序（均匀）的期望 MRR@10 = 0.2622   ← 这是本指标的真实地板，不是 0
  完美排序 MRR = 1.0，因此 MRR 的**可用动态范围**只有 0.738

【缺陷 2/3】LLM「非构造」金标仍然完全锚定在产出 chunk 上
  查询数 N = 632
  LLM 认可产出边相关           : 612/632 = 96.8%
  产出 chunk ∈ LLM 金标        : 632/632 = 100.0%   ← **100%，锚点没有被移除**
  LLM 金标恰好 == {产出 chunk}: 619/632 = 97.9%   ← 97.9% 的查询只有唯一正确答案，就是产出 chunk
  LLM 金标 chunk 数：median=1 max=3 mean=1.02
  → 结论：「非构造金标」这个标签**不成立**。LLM 判定的作用是过滤，不是去锚。
     任务实质 = 「把产出这条边/这个 chunk 排到第一」，与 clue（触发词命中）高度耦合。
