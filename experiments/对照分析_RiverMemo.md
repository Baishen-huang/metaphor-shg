# 对照分析：RiverMemo 拓扑 V3 与 MetaphorSHG

> 本文记录一次外部系统对照分析，它直接催生了第一代实验的两个方向
> （`exp/omega`、`exp/degrade`）。记录目的是**保留机制借鉴的推理链**，
> 便于论文相关工作定位与后续复核。

对照对象：[VCPToolBox](https://github.com/lioensky/VCPToolBox) 的 RiverMemo
拓扑 V3（`docs/RIVERMEMO_TOPOLOGY_V3.md`）。它是长期记忆检索系统，基质是
Tag 图上的守恒传输；本项目是隐喻知识表示，基质是超边与级联归属。**基质不同，
机制可比。**

---

## 1. 结构性相似：都在用"候选是否复现查询侧结构"打分

RiverMemo 的核心裁决量不是"候选和查询像不像"，而是相对拓扑 $\mathcal T(c)$：
候选的有序 Tag 曲线是否复现了**本次查询实际传播形成的河网** $\mathcal R_q$。
其文档明确区分两个命题：「图上存在一条边」与「本次信息确实经过这条边」。

本项目在检索层的核心主张同构：改写型查询切断触发词捷径后，字面通路召回 0.000、
触发词级联通路 0.042、语义超图通路 1.000。这个 1.000 不是语义相似度的胜利，
而是**结构对应**的胜利——候选的超边 n 元喻底结构复现了查询所激活的隐喻结构。

## 2. 逐环节对照

| 环节 | RiverMemo 拓扑 V3 | MetaphorSHG | 对应强度 |
|---|---|---|---|
| 候选投影 | 候选 chunk 展开为有序 Tag 曲线投到场 | 超边 `describe()` 渲染成自然语言再向量化 | 强：结构对象必须先投影成可计算形态 |
| 超集生成 | 六路候选超集，宽松召回后置过滤 | 三通道抽取 / 三通路检索 | 强，见 §3.1 |
| 路径几何 | $Q_i=U_i\sqrt{\max(D_{\min},D_i)}\sqrt{C_i}$，支持域外 $Q_i=0$ | 扩展链四判据（同框架+同源域+喻底交集≥1+间距<3） | 形态同，**取值来源不同** |
| 拓扑审计 | $G_e=A_e D_e^{rel} D_e^{dir} I_e$，$I_e$ 抑制循环自证 | 类型约束 / 语义校验 / 跨模型二评 κ=0.965 | 强，见 §3.2 |
| 可观测泛函 | Ω = 边激活×涌现×流熵的几何平均，**只读查询不读候选**，统一授权结构证据排序权限 | **无对应物** | 缺失 → 催生 `exp/omega` |

## 3. 三处同构

### 3.1 宽松生成 → 严格过滤的双段架构

RiverMemo 生成六路候选超集（宁可多召），再由 Ω 门控的条件创新过滤。本项目的
双段管线是"第一段宽松生成保高密度候选（10×），第二段语义校验保可用精度（4×）"，
抽取侧另有对称的 discover→refine。这不是巧合，而是同一类问题的唯一可行解：
**结构信号的召回与精度不可由单一阈值同时优化。**

### 3.2 循环自证（circular self-justification）

RiverMemo 的相对拓扑含 $I_e$ 项，作用是降低候选文件自身对关系证据的循环自证
（源码 `independent_fraction`）。本项目对应物是自监督排序器的触发词泄漏：
clue 单特征 AUC≈1.0，模型退化成"复读抽取器"；项目称之为"训练信号病理"并做了
机制修复（弱监督把 clue AUC 压至 0.931、泄漏标记 136→23）。

**一个从图结构侧、一个从特征侧，撞上同一个病：打分信号其实来自生成该候选的
那个捷径本身。**

### 3.3 结构收益必须被条件化

RiverMemo：$S_{V3}=S_0+\Omega^\gamma B_G+B_H$，候选局部结构再强，查询河网本身
坍缩时也拿不到完整结构权限。本项目：哈希向量下跨层传播损害检索（−0.104），
真实句向量下翻案为 +0.062。

同一主张形式的两个实例——**结构增量不是无条件正收益**。它还顺带解释了本项目
§6.6 的一个负面结果：图结构连贯度阈值 0.5 完全不起过滤作用（保留链 52→52）。
在 RiverMemo 的设计里，$B_G$ 单独本就不承担判别职责，必须乘 $\Omega^\gamma$。

## 4. 关键差异

**表示层本项目更丰富**：L1 超边是真正的 n 元结构（喻底集合、触发词、情感共边），
L2/L3 是语言学自然结构。RiverMemo 的边是二元 Tag→Tag 加传输率 $P_{ij}$，无 n 元性。
本项目"信号载体是 n 元性、不是层级性"（0.950 vs 0.950，原始嵌入 0.150）这一结论，
在 RiverMemo 框架里无法表述——它没有超边。

**动力学层 RiverMemo 更丰富**：守恒传输（严格次随机 $\sum_j P_{ij}<1$ 保证
resolvent 收敛）、同一算子 $T$ 生成双尺度场、以及"节点势 vs 实际边流"的区分。
本项目的级联查表是 O(1) 离散归属，没有"多少信息真的流过去了"这个变量。

**Ω 是本项目完全没有的东西**：候选无关的查询侧标量。本项目现有验证信号全是
候选侧的，密度指标（6.3 条/百 L1）是**语料**属性而非**查询**属性。

## 5. 借鉴决策：借什么、不借什么

| 机制 | 决策 | 理由 |
|---|---|---|
| 查询侧可观测泛函 Ω | ✅ 借（`exp/omega`） | 补上查询侧标量缺口；可解释 0.042 失效 |
| $\Omega^\gamma$ 门控结构证据 | ✅ 借（`exp/omega`） | 解释 §6.6 连贯度阈值无效；给结构维加查询侧授权 |
| 降级来源封顶可靠度通道 | ✅ 借（`exp/degrade`） | 不丢弃候选、给独立封顶通道，正好补 H1 缺口 |
| 守恒传输 / 严格次随机 | ⚠️ 条件借（`exp/dynamics`） | 谱性质可借；但 $P_{ij}$ 边权不引入 |
| 双尺度场 / resolvent | ⚠️ 条件借（`exp/dynamics`） | 源项机制可借（修复退化）；双场分类不搬 |
| Atomic/Propositional/Narrative 形态 Softmax | ❌ 不借 | 依赖流量图的查询形状分类；本项目查询侧只有三层且很浅，映射过去等于凭空造分类法 |
| 批级条件创新 $\mathbb E(G\mid Z_i)$ | ❌ 不借 | 需定义候选条件协变量并要足够批统计量；收益最不确定 |

**"只借机制，不借基质"**：守恒传输那套依赖"实际承载流量"这个观测量，本项目
的超边是静态文本事实，硬造边权既无语言学依据也拿不到额外信号。本项目已有的
关联矩阵 $H$ 已是正确的图论对象，缺的只是**驱动项**。

## 6. 一个独立的数学发现（催生 `exp/dynamics`）

在核对 RiverMemo 的谱性质要求时，发现本项目 `hgnn.py` 的算子
$M=\tfrac12(I+S)$ 是**无源项扩散**：

```
S 行和 min=1.000000 max=1.000000   ← 精确行随机（质量守恒）
ρ(S)=1.000000   ρ(M)=1.000000
迭代 500 轮后，同连通分量内节点平均余弦 = 1.000000   ← 节点身份被抹掉
```

对比带源项形式 $u=(1-\alpha)S+\alpha T(u)$：分量内平均余弦 0.167–0.211，
**节点保留各自源值**。同一算子、同一图，只差一个源项，从"共识"变成"场"。

这解释了 §6.3 一个未被解释的结果：GRU 共成员序列（1.000）与完整 HGNN（0.950）
打平。无源项迭代收敛到分量平稳分布，等价于对"节点属于哪个成员集合"做平均；
GRU 顺序扫描共成员序列算的是同一件事，所以必然打平。**"聚合方式次要"这一结论
可能是算子退化的产物，而非中性发现。** 该假设由 `exp/dynamics` 检验。

---

## 7. 借鉴的具体落点

**`exp/omega`**：Ω 三分量映射到本项目基质——$\Omega_E$ = 查询触发词激活的框架/
级联数 ÷ 种子触发词数；$\Omega_N$ = 沿级联到达但不在直接命中集里的目标域概念数；
$\Omega_F$ = 激活权重分布的归一化熵。几何平均 + 观测完整度系数，工况分档
collapsed/sparse/dense。**关键性质照抄：只读查询、不读候选**（须写成断言测试）。

**`exp/degrade`**：`F_LLM_*` 候选保留在图中（不损失 +55.8pp 召回），但框架归属
可靠度单独标记并封顶，在结构特征上降权。类型约束由此从"管挂哪个框架"变成
"管这条边能拿多少结构权限"。

---

## 8. 诚实限定

RiverMemo 文档 §15 自己承认 Ω 已成立的是"**可以**测量、**可以**授权"，
**没有**声称它带来下游指标增益。因此本项目借到的是机制 + 一个新可观测量，
不是保证的涨点。Ω 是否能解释 0.042 失效、能否移动指标，由 `exp/omega` 实测判定；
若分离假设失败，应如实报告为负面结果。
