## 0. 结论

| 组件 | 处置 | 依据 |
|---|---|---|
| **HGNN 跨层传播层** | **从检索路径移除**（保留为可选分析工具） | 评分路径**从不调用** hgnn（代码审计）；flat ≡ HGNN 在 18 配置 |ΔAUC| ≤ 0.005 |

**核心原则：删除是安全的，但没有收益。** 因此处置标准不是"能否提升指标"

## 1. HGNN 跨层传播层：从检索路径移除

### 证据

1. **代码审计（决定性）**：检索评分路径 `_pair_features` →
   `extract_features(qe, mapping, self._centrality)`，
   其中 `centrality = 0.5·len(ground) + 0.5·[cascade_id 非空]`——
   **完全不依赖 HGNN**。全仓 hgnn 的引用只有三处：
   `__init__.py`（导出）、`evaluate_hgnn.py`（评测）、
   `evaluate_chain_quality.py`（可选 coherence 过滤，默认关闭）。
   **即 HGNN 从未参与检索打分。**

2. **指标证据**：`flat`（仅 L1 超边，无跨层）与完整跨层 HGNN 在
   18 个 (α, ε) 配置下 |ΔAUC| ≤ 0.005，95% CI 跨 0（`exp/dynamics`）。
   全量 AUC：HGNN 0.915 vs flat 0.910。

3. **算子证据**：现有 `_conv` 是无源项扩散，迭代收敛到连通分量平稳分布
   （500 轮后分量内余弦 = 1.000000）。但在实际工作点 `layers=2` 远未收敛
   （余弦 0.388），故**退化不是平局的原因**——平局是因为该层本就不提供
   检索所需的信息。

### 决策

- **保留 `hgnn.py`**：它是 `metaphor_coherence` 的实现载体，被
  `evaluate_chain_quality.py` 的 coherence 过滤（默认关闭）使用；
  且 §6.3 的"信号来自 n 元性而非层级"这一结论需要它作为对照。
- **从检索路径移除**：既然从未被调用，无需改动代码；但**文档与论文中
  不应再暗示 HGNN 是检索架构的一部分**。已在 §6.3 补附加条件。
- **不再投入**：`exp/dynamics` 已证明加源项不改变结论（|ΔAUC| ≤ 0.005），
  继续优化该层无证据支持。

## 2. L3 级联层：保留但降级定位

### 证据

1. **全单例对照（决定性）**：把全部级联替换为结构上最退化的单例构造
   （每条边唯一 cascade_id），检索 MRR **与生产配置完全相同**（0.5025）；
   只有彻底移除 L3 归属才降到 0.4681。
   → **该层的唯一因果通道是 `cascade_id` 非空这一布尔位**，不是其结构。

2. **构造质量**：生产本体 758 个级联中 752（99.2%）成员共享单一目标域，
   412（54.4%）为单例，中位规模 1。同一"按目标域分组"规则实现四遍。

3. **改规则无收益**：按源域打包使跨目标域比例 0.8% → 51.6%、级联通路召回
   0.042 → 0.076，但**不改变任何主检索指标**。

4. **覆盖率注水**：报出 100% 含 22.4pp 注水（诚实口径 82.4%）。

### 决策

- **保留该层**：级联本体是论文的核心资源贡献（2,177 框架、双语对齐 100%），
  且 §6.3 的层级组织主张需要它。移除会损失可解释性与资源价值。
- **降级定位**：论文中不再把 L3 表述为"检索机制"，改为
  **"检索组织与可解释性"**，并明确当前构造下**对检索指标零结构贡献**
  （已写入 §6.3）。
- **覆盖率双口径报告**（已实现 `health.graph_health(ontology=...)`）。
- **不修订默认构造规则**：改规则会重写 733 个稳定 ID（缓存键、导出、
  Neo4j、双语对齐），而无指标收益。若需运行时组织力，可用
  `orphan_cascade_rule="source_type"`（一行、零风险、不动本体）。

## 3. 特征层的处置

| 特征 | 重标定权重 | 单特征配对 AUC | 处置 | 依据 |
|---|---|---|---|---|
| `sem` | 0.2382 | 0.6277 | 保留 | 唯一有真实判别力的特征 |
| `clue` | 0.4323 | 0.5087 | 保留 | 权重最高但 AUC 低——因锚定口径下它等价于"是否命中产出边" |
| `ground_jaccard` | 0.1711 | 0.5300 | 保留 | 弱但一致为正 |
| `same_frame` | 0.0673 | 0.5053 | 保留 | 接近随机 |
| `same_cascade` | 0.0675 | 0.5070 | 保留 | 与 `same_frame` 冗余 51.7%，但删除无收益 |
| `type` | 0.0168 | 0.5249 | 保留 | 非死维（gen1 的 0.497 是训练集口径误读） |
| `struct` | 0.0067 | 0.5197 | 保留 | **权重已从 0.25 降至 0.0067（原过权 37 倍）** |

**关键判断**：`exp/typefeat` 实测全部处置（删除/替换）的 ΔMRR **CI 全部覆盖 0**。
因此**删除任何特征都不产生收益**，但也都不造成损失。

**决策：全部保留，只重标定权重。** 理由：
- 删除会破坏历史数字的可复现性（旧论文数字依赖 7 维）；
- 保留 `HAND_WEIGHTS_LEGACY` 使历史口径仍可重放；
- 权重错配已修复，特征冗余不再造成实际损害。

## 4. 未做的处置及原因

| 候选 | 未做原因 |
|---|---|
| 删除 `same_cascade` | 无收益（CI 覆盖 0）；且它在 `cascade_id` 非空时才有值，移除会改变特征维度、破坏历史对照 |
| 删除 `type` | 同上；且它承担类型安全约束的可观测接口 |
| 删除 HGNN 代码 | 它是 `metaphor_coherence` 的载体，§6.3 结论需要它作对照；且 coherence 过滤是可选功能 |
| 改级联默认构造规则 | 无指标收益，却重写 733 个稳定 ID |
| 移除 L3 层 | 损失资源贡献与可解释性；且移除后 MRR 反而降 0.034 |
